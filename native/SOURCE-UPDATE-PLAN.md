# 来源变化进入独立版本 / v17

用户已授权继续全部迁移，不再按批请求同意。本项保留原生布局、子页面和既有任务服务，只补来源更新的下游处理。

## 契约

- 沿旧 `discoveryFingerprint` 的含义比较来源标题与说明（压缩空白后的文本）；读取时间、点赞、发布时间、签名媒体 URL、延迟加载的字幕不触发新版本。不能凭文字变化声称视频改变。
- 已有来源元数据不完整时只建立基线，不以人工标题/校对稿推断变更；旧非空说明本次变空视为未完整加载，拒绝写入。
- 首次发现仍使用原任务 ID。真正不同的来源文本保存为新 collection：`sourceRootId` 指向原任务，ID 是根 ID 与规范化来源文本指纹的确定性 SHA256。原任务及原研究文档保持原样；单次保存新版本，无需跨记录事务或更改旧数据库结构。
- 与根或任一已知版本内容相同均复用对应记录，不重复排队，不自动重试失败、取消、恢复后暂停、在途或五次失败任务。旧版本恢复成相同文字不另建重复版本。旧基线、版本身份或作者冲突必须拒绝，不借版本绕过人工改来源的保护。
- 两端来源页以合并后真正新增的任务 ID 排队。Windows 不再把“有文稿/complete”作为跳过详情的条件；held/paused/failed/cancelled/在途仍不自动发现重试。
- 新版本使用本次详情绑定媒体独立下载→本机识别→新研究文档，旧成功可读。缺媒体如实提示，不复制旧音视频、ASR结果或人工文稿冒充新版本成功。
- 任务/研究记录保存根 ID、来源指纹与“来源文本更新”说明，既有页面显示可辨识版本名称。备份恢复保留版本身份，同时沿既有规则暂停任务，不能恢复即自动执行。

## 验证

先失败测试：已有作者冲突、完成资料文字变化、重复/空白/签名变化不重跑、缺说明、无基线、旧文稿和研究编辑保护、手改版本来源/ID碰撞、暂停保护。
再跑 Qt 与 Android 合约、来源页真实控件→受控来源/CDN→下游入库；至少一次 Android 实际离线模型识别。受控来源不写成平台实测；Windows 输入权限问题仍不绕过。
保持原117条映射，不凭本项测试把整条功能计为全部验收。
