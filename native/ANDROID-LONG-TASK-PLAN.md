# 安卓本机长任务：0.14实现与验证边界

2026-10-12。状态：下述服务所有权、通知、取消与中断恢复已实现并在专用API36模拟器验证；不代表完整采集/真机验收。承接持续迁移授权，不新增开机采集、系统保活或电脑代理。运行包及最终回归见native-v14交付记录。

## 改前基线

MainActivity创建CollectionTransfers和CollectionRecognition，在onDestroy关闭。切换内部页面可以继续，Activity销毁会取消。Java本机媒体解码/Vosk识别/研究入库已有真实视频验证，识别文本为待核验初稿。当前导入/模型等控制共享Activity对象；需要消除长任务对旧页面/Activity回调的持有，而不是只增加一个通知。

## 目标与约束

- 用户在可见原生页面主动启动下载、模型准备、导入或离线识别后，非导出的Android Service持有现有worker及应用Context。业务和数据仍在手机，布局和内部页面切换不变。
- service显示可见任务通知，含当前阶段、打开采集页、停止。任务成功、失败、取消或超时即退出前台状态；不空转常驻。通知权限拒绝要在页面明确说明，不假称有可见通知，保留界面停止入口。
- Activity只绑定观察状态；解绑不关闭服务worker，重新进入读现状，不重新提交任务。不能把旧Activity/编辑器引用留在识别回调中；自动刷新不能覆盖未保存校对。
- 下载属于dataSync；API35以上离线音视频处理可使用mediaProcessing，低版本按适用本机文件处理类型处理。按平台版本选择类型；无麦克风/相机/屏幕采集权限，无Windows连接。声明准确权限，禁止借mediaPlayback规避限制。
- 只前台显式操作启动，不从BOOT_COMPLETED启动、不绕后台启动限制。系统停止/超时及时取消网络/线程并stopSelf；不承诺永不被回收或全天无限后台。先采用30分钟本机运行上限，记录可操作的失败/中断原因；该限制需在页面显示。
- 进程崩溃可能无回调：下一次进入把遗留running标interrupted、撤销旧run token，不自动重新授权。用户主动重新开始，原文/媒体/研究修改保留；不宣称字节级续传或ASR断点续算。
- 文件选择仍用系统选择器；传入URI只保留实际获准读取范围，不扩展存储权限、不遍历用户媒体。模型与本机文件仍校验路径/哈希/上限。多任务保持串行、有界，不重复启动。

## 小步实施及验收

1. 先用假下载/阻塞识别器写生命周期失败测试，证明Activity销毁当前会取消，然后实现应用服务所有权和本地状态观察。复用既有工具类，不引入调度框架替换。
2. 将启动/停止/进度入口接service，主线程无长耗时；同一任务重复点击不创建第二worker；快速下载转识别不中断服务。
3. 通知停止与原生页面停止必须取消整链，迟到回调不写入；数据库拒写仍先实际取消。运行中恢复备份同ID旧回调不覆盖新记录。服务意图不接受外部未授权来源。
4. 在专用测试空间、现有API36模拟器运行：启动→离开/销毁Activity→任务继续→重进状态一致→停止→无入库；故意中断→重开显示interrupted；通知拒绝/超时/新旧任务身份各自回归。不得混入正常用户库。
5. 保留真实视频独立ASR验收，再验下载→识别→研究；没有真实CDN成功仍明确未通过，不以受控响应代替。ARM真机、电源管理、多厂商限制另列未验。

## 已打开的官方依据

- [前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)：dataSync覆盖下载和本机文件处理，mediaProcessing覆盖耗时媒体处理；声明相应类型和权限。
- [超时](https://developer.android.com/develop/background-work/services/fgs/timeout)：面向API35及以上，两类服务后台各受24小时内6小时配额限制，onTimeout应及时停止；不能用前台服务承诺无限后台。
- [后台启动限制](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)：前台启动与背景例外不同，本方案只从用户可见操作启动。

上述资料为路线依据；Google Play申报、分发/正式签名、真机和完整生命周期验收尚未进行。

## 本阶段结果

CollectionService拥有独立BusinessStore、Application Context和两种worker；Activity只观察，销毁不停止任务。先落pending标记再启动，结束清除；异常进程重启显示中断且不自动重试。服务非导出、START_NOT_STICKY；无BOOT接收器。API31以上请求立即显示前台通知，通知拒绝在页内说明，通知停止按run身份绑定。

失败测试后修复了：Activity销毁取消、下载遗留令牌、恢复同ID后的错误停止、选择器结果早于服务绑定丢失、迟到下载孤儿文件。真实content://新测试文件已导入后删除自身，未操作用户文件；并非系统SAF选择器完整授权流程验收。专用进程强停重开、真实视频识别/研究入库及原有控件回归另有记录。通知可见性已截屏；旧测试仅查询活动窗口漏掉系统通知窗口，改为查询实际系统交互窗口后通过，不以通知注册成功代替可见。

超时测试调用系统回调，未等完30分钟或实际耗尽系统6小时配额。识别质量、ARM真机、厂商电源管理、来源发现/作者计划、真实平台CDN整链仍待实施或验收。完整范围见ADR014与CONTINUATION-PLAN-v14.md。
