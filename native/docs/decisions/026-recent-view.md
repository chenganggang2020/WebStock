# 026 最近查看：主动行为与临时行情分开

本轮用户已授权全部剩余迁移和并行子任务。v25切片覆盖 D08 的 Windows 部分；下方后续工作副本追加 Android A10，不扩大成浏览器历史或自动荐股。

## 行为

- 独立 `recent-v1.sqlite` 保存明确证券 `market:type:code`、最近主动查看时间、次数及带来源的报价快照；不写旧生产库。
- 启动恢复、布局切换、分组筛选、行情回调不计次。报价总览单击只选择；主动展开图表/打开详情/信号解释才记录。所有业务到详情的成功跳转也记录。
- 最近查看复用原生内部子页；搜索、排序、打开行情/信号、加入自选、带入账本表单、删除、清空和 CSV 导出均有操作。账本仅预填为新增，不自动记账或下单。
- 临时打开旧记录走现有行情来源和缓存，但不写入、导出或显示成自选。只有显式“加入自选”才提升成自选。总观察范围仍有界，不打开全市场轮询。
- 旧库仅只读预览，确认后导入专用库。同一导入指纹不覆盖本机修改；删除/清空后重导同一旧记录不复活。

## 独立审查已修复的边界

- 无市场的 000001、899050 等歧义旧记录隔离为旧身份，不能向股票/指数猜测跳转，不能继承到后来明确身份的次数与报价。
- SQLite 外部排他锁导致原生页同步阻塞的复现从约6秒改为约129毫秒有界失败；保留旧表及错误提示，不宣称已经异步化。
- CSV 先写同目录临时文件，再以拒绝覆盖的改名提交，不能覆盖在检查之后并发出现的目标；失败原文件保留。独立竞争写者已复验。
- 最近100条仅为新增观察标的读取缓存，不反复重读已有全自选；批量观察后主窗口统一刷新一次。同一隔离库100项观察从104141毫秒降至66毫秒，未改变1000毫秒测试预算；这不是生产全量行情压力验收。
- 旧时间无时区时依旧服务北京时间解析，内部保存 UTC；最新报价/取得时间/查看时间分开。缺失价格不填零。

## v25之后的 Android 工作副本（未发布）

Java `RecentStore/RecentLegacy/RecentScreen` 已接首页“最近”内部页。搜索排序、旧记录文件预览/确认、报价与信号跳转、显式加入自选、新账本预填、删除清空及CSV导出均有独立实现；手机直接走已有HTTPS来源，不代理电脑。身份、歧义隔离、源时间和主动计次规则与上述Windows合同一致。观察标的限量，不把临时观察保存进自选文件。

采用单线程后台存储和页面读代次，防止迟到刷新覆盖用户的文件取消/清空确认。系统文件返回时先核对导出数据并取消旧读；否则页面重新可见会取消合法的排队导出。该竞态有独立RED与真实content URI返回回归。账本遇到未保存草稿不会被预填覆盖，也不自动新增交易。

本批模拟器证据在 `parallel-20261012/android-recent`、`android-indicator-chart`：模型34、原生页面146、主入口142、账本123、临时行情32各自为不同测试模式，不相加为功能数；部分模式包含共用基础断言。文件导出检查经过真实Activity结果回调及系统内容URI，但未声称外部文件选择器全部人工操作或ARM真机已验收。v25交付包未被覆盖。
