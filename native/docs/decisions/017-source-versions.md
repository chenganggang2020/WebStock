# ADR017：来源文字变化保存为独立版本

日期：2026-10-12。Windows / Android 0.17；全部迁移目标仍 active。

旧程序 discoveryFingerprint 以规范化标题和说明判断变化。两端沿用此含义，不以发布时间、点赞、签名媒体地址或延迟加载字幕触发重新识别，也不凭文字变化断言视频发生变化。

保留原 collection 和人工研究稿，新增确定性 ID 的 collection：source-version:SHA256(rootId + 换行 + sourceFingerprint)。指纹为压缩 Unicode 空白后的标题与说明。新记录带 sourceRootId、sourceFingerprint、sourceRevisionKind=source_text_v1、sourceRevisionAt；不复制旧音视频或识别文本冒充新处理。每次只保存一条新记录，不引入多记录事务或旧生产库结构变化。重复当前版本或回到任一已知版本都复用已有 ID。

元数据不完整只建立基线；已知非空说明突然变空则拒绝。作者冲突、原基线与指纹不符、版本身份/来源被改或根重复时不写库。家族任一任务暂停、失败、取消、在途、中断或失败达到阈值时，不借新版本绕过保护。两端来源页使用合并结果的实际 ID 决定是否提交下游，不再把完成文稿一律略过。

新版本继续已有下载→识别→研究流程；研究结果复制来源版本字段，默认待核验，旧人工稿保持。任务标题用“来源更新 + 短指纹”区分。查看来源初版在原生子页内进行；未保存编辑包括换行均阻止切换。Qt 同时更新列表选中项；Android 比较原始输入文本，避免 trim 丢失换行或误判旧稿。

验证：Qt 来源合约26项、来源控件13项及完整24组 CTest；安卓新增版本、失败状态、来源基线、导航换行测试及完整28模式。先红后绿保护失败/暂停状态、根指纹冲突、列表选择和未存空白编辑。日志以 native-v17 最终验收记录为准。

Android 在专用 API36 x86_64 模拟器用32.7秒旧视频实际解码、Vosk识别并生成独立研究稿；来源 HTML 和 CDN 响应受控。Qt 新版本控件链使用受控媒体与识别程序，不能称此次完成实际桌面 ASR 或平台全链验收。外部实时资金仍未恢复，不因回归成功而改写来源状态。没有真机、全历史、全部117项或商业转写质量验收结论。
