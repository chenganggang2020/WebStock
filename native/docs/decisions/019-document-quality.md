# 019 文稿质检与复核

状态：已实现阶段功能，整体迁移未完成。依据旧 creatorDocumentState.js，机器准入和事实核验必须分离。

采用无UI纯规则 collection_quality.hpp / CollectionQuality.java，Qt文稿标签与Java内部质检区共用行为契约。safeSource仅迁移质检字段，不带会话/签名URL。旧ASR正文基线缺失如实提示，不能以旧completed推定质量通过；OCR需页序/页数/正文对应。新本机ASR缺时长/分段或正文不符不通过。

复核事务读取最新正文校验SHA256，记录非空说明、毫秒UTC时间与transcript_only范围；两端Unicode空白一致，哈希保留原文。正文改变自动显示旧复核过期。普通后台保存从库取最新复核历史，避免旧快照覆盖；备份不接受不完整复核项。

真实旧数据包18,804,999字节，原16MiB约束导致迁移拒绝；两端业务备份/迁移改32MiB上限，普通文本仍原限制。无截断，无无限制读取。大型库后续需要分包/流式迁移，不宣称任意大小支持。

入研究资料附qualitySnapshot作为当时质量记录，verification保持unverified，既有资料不覆盖。未增加自动事实验证或购买数据源。

验证：共享9例、原生控件、过期/后台保存/Unicode/草稿切换与新增保护；985真实旧文稿两端全数分类一致。测试与真机/算法正确率/官方平台长时分别记录。
