# 033 本机持仓镜像与设置接入

2026-10-13，用户持续授权全部迁移；沿已有Qt/Java原生布局和内部子页面，不引入新技术栈或在线权限。

MigrationStatus只读随包117项JSON及精确ID+route白名单，不读取任意文件。AI偏好只存非敏感参数；能力声明、验证状态与实际在线消费者分开。Android编辑/阅读长状态用本机完整存储和指纹标记，避免大正文进入Binder。

PortfolioMirror从现有完整账户/交易/证券与旧快照只读提供器生成冻结证据，写独立SQLite。明确accountId与exchange:type:code；旧证券缺冗余code时仅从已验证完整id投影，原集合不变，坏code不自动修。完整性只指全部本机记录，不等于券商记录齐全；读取时刻不能当账本或行情源时刻。确认前重核冻结账户/证券/账本上下文和历史版本指纹；取消不写，变化要求重新预览。

镜像不执行旧服务的买入流水补造和现金覆盖。Android PRAGMA写入用实际消费的rawQuery并读回标记；历史未知库拒绝且保留，失败隔离测试库不靠删重建通过。宿主SAF严格UTF8、32MiB界限；JSON/CSV/TSV均先预览再确认。数据库全正文分段读，屏幕分段阅读，导出不截断。
