# 020 原生作者观点关系与版本

状态：阶段实现，P017/P018部分迁移，不是整体完成。

依据旧 creatorIndustryService 与作者图/表的语义，先接文稿准入、连续引文和原生编辑，不臆造自动提取。Qt QGraphicsView、Android Canvas 绘制局部关系；完整关系始终可从表/列表读取。图最多显示所选实体12条邻接关系，覆盖计数可见，不把局部图叫完整作者图。

每篇 collections.creatorAnalyses 保存最多100次修订，每次含正文原样快照及SHA256、来源身份/标题/作者/发布日期/URL白名单快照、版本ID、UTC时间、模型/人工来源、摘要和最多500条关系。来源字段后改不篡改历史归属；旧版没有来源快照时明确未知，不回填当前字段。引文必须是12至500字连续原文，两个实体均在引用内。七种关系类型和支持/相反观点有白名单；仅标作者观点，不能自动升级事实或证券映射。

保存事务重读当前正文及最新版本ID，旧编辑或识别结果不得覆盖新版本。普通采集保存保留已存关系历史。当前图需要正文哈希一致、v2规格及文稿质检准入，旧资料还要求primary证据；明确零关系修订不同于从未分析。历史快照只读，但不删除，备份恢复保留它们。

Qt拦截同文稿/同行重选造成的草稿覆盖；Android关系类型/方向与文本均纳入未保存检查，实际Activity重建保留草稿及并发基线，重建时重新检查当前准入，不得把旧分析复活。保留既有内部子页、三桌面布局和安卓独立存储。

边界：本次是单文稿人工观点关系，不是自动AI提取、跨文稿作者聚合、公司收入核验或历史图文件全迁。旧运行目录未发现creator-industry文件夹，不能把新测试关系说成旧真实作者图。无新依赖，无SQL模式升级，不改旧生产库。
