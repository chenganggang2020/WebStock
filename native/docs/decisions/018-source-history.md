# ADR018：来源历史独立迁移、分页与导出

日期：2026-10-12。Windows / Android 0.18，全部迁移目标继续 active。

## 旧业务及数据

对照旧 `douyinSyncStateService.js` 和 `expert_sync_runs` / `expert_sync_run_items`，以旧程序数据库只读快照为依据：5,515轮、7,160条作品明细、4作者。旧 completed 仅表示该轮结束，不能等同转写成功或研究入库。旧库不改写；来源库身份不自动转换为运行计划、授权或新采集任务。

`native-source-history-v1` 白名单保留旧轮次身份、作者、原始起止时间、状态、计数、错误和逐作品处理结果。缺失数值保留缺失，真实0保留0；剥离URL查询/片段；不带 result_json、会话、媒体、模型或密钥。单包32MiB、10,000轮、单轮2,000明细、全包50,000明细，超过上限显式拒绝，不静默截断。

## 原生存储和操作

独立 `legacy_source_runs` 表，与本机原生 source runs 分开。Android计划库1→2只新增表，不清空原计划。预览后确认导入；相同ID相同内容保留，冲突整批回滚。50条/页，首次读取保存最大rowid作为分页快照，新记录不会挤动当前旧页；刷新才重取边界。导出该快照的全部记录，不仅当前50条。原生轮次导出带各平台独立schema，不能作为旧历史导入。

历史详情→对应本机文稿使用来源URL或旧 content ID 匹配，未匹配/多版本不随意挑一个，不触发采集。未保存校对（包括换行）阻止跳转。继续内部子页，不新增业务弹窗。

## 文件与生命周期

桌面历史读取、验证、导入、导出在工作线程执行，页面只接收结果；销毁后不投递UI回调。工作线程持有独立账本引用，导入检测取消并事务回滚。导出只接受新的.json，使用独占新建，绝不覆盖既有库或文件。

Android文件读取/导入继续单后台执行器；选择文件时捕获导出类型与rowid边界，通过小型Bundle保存。Activity重建后不依赖旧View处理结果；导入仍需确认，未确认的大包不塞进Bundle。计划库的关闭标记先置位，事务/查询与close同生命周期锁，关闭后不可重新打开、提交前检查取消。

## 验证边界

确定性测试覆盖重复/冲突回滚、超过200轮、分页插入稳定、路径覆盖拒绝、锁住旧库时UI可响应、页面销毁、安卓重建文件回调、未存校对、旧库升级和验证期间关闭/替换owner。真实旧记录在两端独立测试库验证数量和全量导出；安卓仍为API36 x86_64模拟器，无ARM真机结论。最终结果见 `output/native-ui-design-20261010/native-v18/acceptance.json`。

这不是整软件备份、全部117功能验收或真实平台自动采集完成；媒体/模型/会话不在历史文件内。实际官方来源链和资金实时可用性独立记录，不能用历史记录或受控网络测试替代。
