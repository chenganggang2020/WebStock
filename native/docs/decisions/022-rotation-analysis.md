# 022 原生轮动窗口、排行和曲线

状态：0.22 阶段迁移；D13仍为部分完成。依据旧 `sectorRotationModel.js`，两端领域实现分别为C++和Java，不引入图表网页。

同一榜单共用一个可用历史终点，行时间仍用各行真实抓取时刻。5/15/30为交易分钟：午休压缩、端点容差75秒、相邻有效点最多150秒。来源完整元数据、模型版本、范围、覆盖数、日期必须一致；未来记录、日榜、缺板块、无效金额不生成窗口。共同终点可能早于当前所选采样，界面并列显示，不能伪称当前实时。

金额用整数分作差。速度为净额变化/实际交易时长；速度变化为当前速度减相邻前窗速度，单位仍为元/分钟，不称物理加速度、逐笔流入或买卖建议。前窗不足为未知，不补0。四种方向排行用代码稳定处理并列，0不属于正负榜。

两端原生曲线分别使用QPainter、Canvas。净额和涨跌幅独立坐标轴；固定09:30—14:57连续交易时间轴，11:30/13:00同一坐标；实际缺口及模型版本变化断线。日榜不能冒充盘中曲线。列表、曲线、明细仅切换内部区域。

分析移出UI线程，快速切换按世代丢弃旧结果，内层循环定期检查取消。新选择先清空旧曲线与明细。批次窗口预筛、反向有界查找、同批次时间缓存降低大概念榜开销，不改变旧窗口规则。安卓不把全日JSON写入Activity Bundle；重建时重新读取专用库。横屏低高度时筛选区在左侧独立滚动，右侧保留图表/列表；窄屏高度不足时限制控件区，保证结果仍可见。

验证：用只读10月9日真实旧档案经旧JS计算18组基准，比较全部板块、窗口端点、数值及四种排行顺序；两端另测来源模型版本、缺口、未来点及取消。受控样本与真实旧档案分列。Android模拟器不是ARM真机；Qt控件测试不是受限制Windows桌面的OS指针验收。接口是否实时可用是独立问题。

不改生产库，不重新迁入已有1446记录，不新增自动轮询和权限。初次Android基准测试因重复加载多份真实档案触发内存不足，改用页面已经加载的一份数据后保留全部比较，不能以缩小样本掩盖失败。
