# v28集成与并行工作隔离

Windows只由CMake显式列出的模块参与本次构建。Android的Java源码默认自动包含，v29评论工坊和个股研究仍在其他两个窗口集中修改时，会污染已冻结v28的验证。

本阶段使用显式构建参数 `-PfrozenMigrationV28=true`，只排除尚未接主页面的 `CommentWorkshop*` / `StockResearch*` / `News*` 主代码及专属检查，不排除任何v28功能、失败检查或旧功能。正常未加参数的构建仍包含全部Java源码。三模块接入主页面前必须移除该参数并做各自必要检查，不能将v28检查算作v29验收。

v28专属设备检查仅NativeReview/emulator-5564；独立启动测试任务，系统文件选择器用完关闭；每个检查120秒上限，超时如实失败并停止该测试进程，保留数据。5562及生产库不使用。已通过且未改的1604旧核心不重复。

数据边界：研究运行保留旧原文、全部原始字段和来源规范指纹；本机保存时间不等于旧报告时间。大SQLite记录在同一事务分块读回，不截断。源分析/交接及人工龙头用各自独立库，不声称全软件备份已包含这些独立库。平台采集登录、CDN全链与分钟资金仍有原先来源限制。
