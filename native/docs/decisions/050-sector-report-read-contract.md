# 板块/产业报告：保存范围读取与不可见动作边界

日期：2026-10-14。状态：工作50实现；不是实时源或线上AI验收。

报告保存必须在来源版本检查仍受保护时完成。Android真实Main曾在SectorResearchStore.saveAiReport的附加业务库写事务内，经Main的scope回调调用BusinessStore.read(topics)，从另一个连接开启写事务，产生SQLITE_BUSY。把来源检查移到事务外会引入检查与保存之间的变化窗口，因此没有采用。

仅为该消费者增加SectorReportReader.topics和Main.sectorReportScopes。它们从已存在的业务库读取完整主题记录，在API35及以上使用真正只读事务；API26–34在打开文件前拒绝。既有BusinessStore、人工材料路径和保存事务不变。无库/损坏/外来库不会被接管或重建，超出完整读取边界明确拒绝、不截断。

Qt原人工页面的按钮连接还包含独立persist回调；只在按钮业务动作中检查AI子页不足以保护离页草稿。因此manualActive同时用于原人工动作和persist，检查可见、启用、窗口非最小化和应用前台。内部返回保留草稿，不以回主页恢复访问历史。

当前证明：Qt旧回调实际反例失败后修复，仅复跑受影响case；Android实际Main85与真实隔离SQLite55通过，包括取消、来源变化、显式保存、完整历史和只读损坏保护。默认无Grant和凭据，受控本机返回不是线上执行。安卓横屏阅读问题另做可视修正，模拟器不是ARM验收。
