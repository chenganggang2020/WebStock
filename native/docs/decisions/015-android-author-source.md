# ADR 015：手机来源发现连接本机下载、转写与研究

2026-10-12，已实现首条可操作路径；不代表全部业务或平台链路验收。沿用户持续迁移授权，不逐批再问。保持Windows三布局与Java内部页。

## 决策

作者来源是原生Java子页，不使用网页渲染业务列表/编辑器。仅外部平台来源会话使用受限WebView，构建时复用桌面审查过的只读提取脚本；未复制旧账号、Cookie或密钥。允许www.douyin.com/douyin.com HTTPS，禁止文件/content、混合内容、任意外跳、上传和网页原生桥；TLS错误拒绝。API28以上正常与测试会话使用不同数据目录。API26–27仅正常发行可用，未在同进程混用测试会话。

手机版实查跳向m.douyin.com，被当前允许范围拦截；增加用户可见“官方桌面网页”显示选项，采用普通浏览器的桌面网页请求及缩放。没有放宽域名、关闭TLS或绕过登录/验证码。桌面页实查加载后返回平台异常，不当作零作品成功。

## 操作与数据合同

研究→采集文稿→作者来源。填作者主页、授权依据、1–50上限，打开官方页；用户本人处理登录/验证、滚动加载，读取本页，再主动开始。只处理当前页读取作品，不宣称全部历史或默认持续后台爬取。

逐项核对URL中的作品ID与稳定作者；媒体仅接受同ID/作者的embedded_detail绑定，不用video元素的预加载地址。相对日期不编造绝对时间；来源描述单独存sourceMetadata。重复作品保留人工标题、原稿、校对和研究编辑，不自动重跑失败/暂停/已有任务。新作品缺媒体保存为待处理，用户可主动导入有权处理的本机音视频。

新且具备媒体的条目提交CollectionService，真实观察下载、ASR和研究记录后再推进下一条，不能以“已排队”算完成。来源本轮设置和最后回执存在独立SharedPreferences；不是完整多作者计划库、全部历史或业务备份覆盖。这些仍是下一步。

## 生命周期与修复

- 离开来源、后台或Activity销毁停止后续发现；已提交的手机服务可以继续。返回同一来源页实例仍保留所属run，可明确停止本轮；不得取消另一个手工任务。重建页不自动恢复发现，服务任务从文稿页核对/停止。
- 观察下游完成时核对executionRevision；恢复同ID旧成功备份不算本轮成功，也不继续处理下一条。
- 只读快照校验导航generation和URL；主框架网络/HTTP错误、SSL错误按当前目标URL过滤。旧不同URL错误和关闭后的回调不得停止新轮次。相同URL快速重载、全平台重定向矩阵尚未全验。
- 发现、停止先撤销内存轮次；运行回执写盘失败停止发现，不让重试循环继续采集。停止仅针对本轮所属服务run。

## 验证边界

native-v15保存红绿测试、截图和真实网页观察。控制源HTML由真实Android WebView运行共享提取器；下载响应受控、32.7秒旧授权视频在手机实际解码/Vosk识别并研究入库。重复阅读不重复下载，旧人工稿保留。停止句柄、备份替换和旧导航错误三个P2均先复现再修，独立只读复审未见新增P1/P2。

这不是抖音/CDN在线全链验收、文字准确性证明、真机或全长时运行验收。实际网页加载异常仍待恢复/用户会话验证；没有代登录。实时资金旧两接口复查仍ECONNRESET。最终通过模式以native-v15/final-*.txt为准。
