# ADR016：安卓作者计划、前台调度与独立历史

日期：2026-10-12。状态：本阶段实现，全部迁移目标仍 active。

## 背景与选择

旧程序及 Qt 0.13 已有多作者计划；安卓0.15只有当前作者与最后回执。选择在现有 Java 作者来源子页添加 SourcePlansPanel，使用独立 SourceSchedule SQLite 库，不更换导航/布局、不改旧生产库或现有业务表。来源页面发现依赖可见官方会话；不以系统后台服务强行长期驱动网页。CollectionService 继续持有已提交的下载、解码、识别和研究入库任务，手机不依赖电脑。

保存、启用计划和恢复全局调度是三个动作。最多50作者，每轮1–50条，间隔10–1440分钟。只有主动恢复且来源网页前台可见才依次执行；一个轮次完成再推进下一作者。下一到期时间从完成时计算，不补跑所有错过周期。平台异常暂停全局调度；离页、后台、重建和重启不自动恢复发现。当前页面首批已加载作品不等于作者全历史。

## 数据与恢复

- 计划和每轮配置快照/计数/结果在独立库保存；部分唯一索引限制同库只有一个 running，进程内限制同路径单持有者。只有同一 running ID 可写回执，终态不可由重复回调改写。重新开库将遗留 running 标为 interrupted，不自行开工。
- 终态落库后才清内存运行标记。即使磁盘写失败，实际停止仍先执行；存储恢复后可显式修复当前遗留轮次，不修改已有终态或其他 ID。测试注入 SQLite 临时失败验证此边界。
- 历史列表最近200轮，完整历史仍保留本机库；每轮详情可打开具体文稿。旧程序历史迁入、更多分页、历史导出尚未完成。
- 计划备份格式 `native-android-source-plans-v1` 只含配置，不带会话、执行许可、运行历史、音视频、模型或研究文稿。不是七类业务备份，也不冒充 Qt 数据格式兼容。重复作者保留本机，新作者默认停用；预览后才事务合并。

## 文件与异步边界

系统文件提供者读写在独立线程，导入上限2MiB。预览仅保留规范化配置。文件迟到回调不会导航，不会停止之后启动的新轮次；仅原计划面板仍可见且没有执行/调度时刷新预览。Activity 销毁关闭后忽略回调。外部提供者不保证原子写，导出中断可能留下不完整目标文件，必须重新导出核验，不能宣称失败文件已自动撤销。

## 验证与非结论

专用 API36 x86_64 模拟器执行真实 Java 控件、SQLite、WebView、文件提供者、下载文件、解码和模型。两作者串行测试使用受控来源/下载及受控识别；另外 `business-source-chain-real` 用32.7秒旧音视频完成手机实际 Vosk 与入库，但来源 HTML/CDN 响应仍受控。不能用这些通过替代真实平台登录/CDN成功、转写质量、ARM真机或长时后台验收。

红绿测试覆盖终态写失败、慢提供者阻塞UI、慢导入打断新轮次；最终日志在 output/native-ui-design-20261010/native-v16。测试延迟提供者只声明在测试 APK，主 APK 不包含该组件。

真实平台上次返回加载异常，资金旧公开接口上次断连，v16不因实现计划而声称这两项恢复。已有作品目前只更新元数据、不重跑或覆盖人工稿；实质内容变更的版本化更新是下一迁移项。桌面0.13、原有三布局及内部子页面保持。
