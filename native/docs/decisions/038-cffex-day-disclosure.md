# ADR-038: 指定日股指期货披露独立留存

日期：2026-10-13。状态：实现中，等待本轮最终宿主验收；不是数据源可用性批准。

## 决策

CFFEX日终会员排名独立于IF0/IH0/IC0/IM0连续行情。用户选准确日期和品种，单次有界请求；不存在/失败保持原历史，不找邻近日期代替。显示真实月份编码、榜内多空及未知值，不称全市场资金净流入。页面明确来源、接收时间及未独立核验的交易日历/挂牌状态。

使用专属JSON历史和比较版本保存，不写旧生产库。最多20份/16MiB，满档拒绝而非静默淘汰。原文UTF8字节、BOM、摘要及解析结果可重算；冲突编码拒绝。Android恢复文件存在时保持原样，由用户明确恢复，不通过只读API暗中修复。

C++ Qt Widgets与Java Views各自实现。桌面为资金内部页，Android为市场内部页，原文先返回榜单、其余回主页。离页取消请求，完整阅读状态私有保存，Android页面重建标识只含摘要。

## 验证边界

专项覆盖确定性原生控件、保存/取消/历史/恢复、字节保护与来源合同。可控网络fixture清楚标为构造材料，不能证明当前交易所来源成功、ARM设备或全业务验收。没有采集登录、在线AI或交易操作。后续真实来源只在用户明确操作或有新证据时单次检查。
