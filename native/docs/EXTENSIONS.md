# Stock 图表插件

基线：3243a396bfa4a4be9cc6ecb55547d66c75624930。保留该版本行情刷新恢复、导航、数据位置和业务库逻辑。

## 使用

右上角设置 → 插件管理 → 安装“策略回测”（或导入 .wspkg）。
安装后，当前主图工具栏出现“策略”。选择股票日 K，选择日期，点击“运行”。
计算使用主图同一份已加载行情；“刷新行情”交给原 MarketFeed，插件不创建第二套行情库或下载器。
日期选择受已载入完整历史范围约束，不把超出来源覆盖的区间宣称为完整数据。

默认只显示简短数据状态、图层开关、彩色策略线图例、结果卡片及图表。来源、单位、成交规则和限制在“数据与规则”内；完整原生报告和历史记录按需打开。
结果是历史模拟，不会提交真实交易。首个策略依然是 Backtesting.py 的双均线示例，未完整模拟 A 股 T+1、涨跌停和历史税费。

## 扩展边界

- 主程序提供独立扩展管理、参数表单、已加载行情快照、通用图层（线/标记）、结果曲线和表格。
- 包的 ui.apiVersion=1、ui.placement=chart 声明入口；operations 声明参数。
- 计算运行在独立 Python 进程；现有 QProcess 超时、进程组终止、冻结输入与结果校验被复用。
- view.schema=webstock.chart-view.v1 由插件提供指标名称、显示数值、日期/价格坐标、结果曲线及表格映射。主 K 线不含 SMA、Backtesting.py 或其他引擎专用字段。
- 新策略遵守接口后，不必修改主程序菜单、绘图函数或重新编译 Stock.exe。
- 插件为本机可执行代码；进程隔离用于生命周期和故障控制，不是权限沙箱。
- 首版图表扩展入口支持单只 A 股股票日线。其他输入类型的旧研究包没有被冒充为已适配。

## 生命周期与数据

扩展登记存放于现有数据目录的 extensions-v1。原 quant-plugins 预览档案保留，不自动执行旧包。
共享行情仍位于原 live/market-v1.sqlite，业务数据位置不变。

安装校验包内文件摘要和接口版本，分阶段写入；禁用和卸载先销毁该插件拥有的面板、按钮及图层，终止其运行任务。
卸载移除该插件所有已安装版本。默认保留历史结果与参数；取消勾选后清理该插件的历史。为支持复核，保留的历史含冻结输入与代码快照，不是可启动的安装版本。
其他窗口仍持有任务锁时拒绝移除文件。共享运行环境不随单个插件卸载删除。
切换股票/数据版本会取消旧任务、清空旧图层；只接受与当前行情身份和输入摘要一致的结果。

## 运行环境

交付安装使用已验证的独立 Backtesting.py 环境，精确插件 ID 到解释器的映射保存在 runtime-defaults.json。
包不能自行指定任意解释器路径。缺少环境时不会自动猜测或调用系统 Python；插件详情提供已有环境选择。
运行结果记录实际依赖版本。迁移到另一台机器须先准备相同依赖环境；当前本机交付不宣称是跨机器免安装运行时。
已验证的直接依赖见 quant/plugins/requirements-backtesting.txt；Backtesting.py 固定到官方仓库 ca2e2611621e472542ba90f7243a1fa06a7d7108，算法未重写为 C++。

## 构建与检查

使用现有 Qt 6.9.1 / MinGW 与 WebView2 SDK 构建 MarketNativeReview、stock_extension_tests。
运行 python quant/plugins/build_extension_package.py --output 包目录 生成插件。
将生成的 .wspkg 放到程序旁的 plugin-packages 目录，或在设置中导入。插件中心显示本地提供的包；较新的版本提供“更新”按钮，无需重新编译主程序。
运行测试前设置 WEBSTOCK_EXTENSION_PYTHON 为已验证的 Python 路径，WEBSTOCK_EXTENSION_PACKAGE 为生成的 .wspkg，再运行 stock_extension_tests。

测试涵盖独立启停/卸载、不兼容及损坏包、历史保留、共享缓存不变、跨窗口活动任务、运行中卸载、当前基线设置入口、真实股票回测和切换股票后的旧结果失效。
公开股票验收样本为腾讯 K 线的平安银行前复权日线（2024-03-04 至 2026-10-23，640 根），采集于 2026-10-24 06:23:49 UTC。它是固定回归样本，不代表最新行情或收益承诺。
