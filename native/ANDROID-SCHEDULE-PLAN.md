# 安卓持久来源计划 / v16

用户授权继续完成全部迁移，本阶段不逐批再次审批。保留既有 Java 原生布局、子页和 CollectionService；只扩作者来源页，不改旧库、桌面或包名。沿用 karpathy、分段实现和先失败测试；不提交远端。

## 合同与顺序

1. 独立本机 SQLite 计划库：作者稳定身份、最多50计划、每轮1–50作品、10–1440分钟间隔；保存不启用，启用不代表调度已恢复。进程/页面重建后运行中记录变中断，调度关闭，不补跑全部错过周期。运行历史不可被重复完成回调改写，最近200条展示，库内保留历史。计划修改不能覆盖正在执行的计划快照。
2. 原生计划/历史面板：保存、选择、启用/停用、单次执行、显式恢复/暂停、运行详情；来源网页只在当前可见页面发现，离页或切后台暂停发现。下游沿用手机服务执行，明确停止只取消当前来源自己提交的任务。新作品仍真实下载→识别→研究，不退化为check-only。已有作品实质变化更新是后续切片，当前保持人工稿不重跑。
3. 单次与调度共用来源身份/合并/下游路径；主页自动加载后读取当前首批已加载作品，不承诺作者全历史。不登录、不跨验证码、空页或平台失败立即暂停全局调度，保留失败记录；不以周期不断重试平台故障。
4. 计划专用文件导入/导出：只含作者配置，不带会话/密钥/执行许可。导入先预览，再显式合并，重复作者保留本机设置，新作者默认停用；整体事务，非法文件零修改。运行历史保留本机，导出文案明确不是完整业务备份。
