## 0.14 安卓本机任务（不依赖电脑）

“研究→采集文稿”保持现有原生编辑页，下载、音视频导入、模型准备、离线转写交由手机本机服务执行。切换子页、重建或关闭Activity不会取消已启动任务，重新进入观察原任务而非重跑。每次最多30分钟，任务完成/失败/停止后退出前台，不闲置常驻，不在开机或进程重启时自动开工。
