# 首页市场交互对比 V3 规格

## 目标

首页市场驾驶舱同时支持：

1. 八个主要指数卡片在真实分时线与日 K 线之间切换。
2. 主走势图按用户选择的指数、行业板块或概念板块进行对比。
3. 相关性矩阵跟随用户选择，按共同交易日的日对数收益率计算。

## 数据真实性边界

- 指数分时必须使用带交易所前缀的显式白名单标识，`上证指数` 固定为 `sh000001`，不得经过股票代码首位推断。
- 分时数据只展示供应商实际返回的分钟点；休市时标注“最近交易日分时”，不声称实时。
- 日线比较要求每个对象至少有 `窗口 + 1` 个有效收盘点，样本不足明确不可用。
- 板块目录和板块日线使用公开市场板块标识；当前可验证的银行对象使用中证银行指数 `399986`，不能用 WebStock 本地观察分组冒充市场板块。
- 不用股票样本平均、0 值或生成数据补造板块指数历史。

## 交互合同

### 指数卡片

- 顶部提供 `分时` / `日线` 两个全局模式按钮。
- `分时`：八张卡片显示最近交易日的真实分钟线，并显示交易日期/截至时间。
- `日线`：八张卡片显示最近 20 个交易日的真实 OHLC 蜡烛图。
- 切换只改变图形，不改变卡片当前点位、涨跌幅和成交额口径。

### 对比对象选择

- 默认选择：上证指数、深证成指、创业板指、科创 50。
- 可搜索并选择指数、行业和概念；始终保留用户选择顺序。
- 最少 2 项、最多 8 项；超限或低于下限时给出就地提示。
- 选择器展示数据类型与公开来源；不可用对象保留明确状态。
- 选择结果本地保存；失效或已从目录移除的键在下一次加载时剔除。

### 主走势图与相关性

- 分时模式：主图以昨收为 100，对齐所选对象的分钟标签，比较日内相对强弱。
- 日线模式：主图以所选窗口共同起点为 100，支持 20 / 60 / 120 日。
- 分时模式按成对共同分钟的对数收益率计算 Pearson；日线模式按成对共同交易日的日对数收益率计算 Pearson。
- 相关性样本数小于 20 时显示“样本不足”；相关性不解释因果。

## API 合同

### `GET /api/market/comparison-catalog`

返回统一目录：固定指数 + 可用公开行业/概念板块。每项至少包含：

- `key`: 稳定命名空间键，例如 `index:sse`、`sector-index:bank`、`eastmoney-industry:BK0475`
- `kind`: `index` / `sector-index` / `industry` / `concept`
- `name`, `code`
- `capabilities.daily`, `capabilities.intraday`

### `GET /api/market/comparison-history?window=60&keys=...`

- `window` 仅允许 20 / 60 / 120。
- `keys` 去重后按请求顺序返回，数量 2 到 8。
- 返回 `series`、共同起点比较 `comparison` 和成对相关性 `correlation`。

### `GET /api/market/index-intraday?keys=...` 与 `GET /api/market/comparison-intraday?keys=...`

- 指数卡接口只接受固定指数白名单键并缺省返回八个主要指数；比较接口接受已验证具备分时能力的指数/板块指数键。
- 每项返回实际分钟点、交易日期、昨收、抓取时间和市场状态。
- 盘中短缓存，休市较长缓存；请求失败时明确 unavailable，不回退到股票代码接口。

## 图表合同

- 分时图：多序列折线，无面积堆叠，昨收 100 参考线；时间轴压缩午休空档。
- 日线图：多序列折线，起点 100；卡片内使用 OHLC 蜡烛。
- 相关性：矩阵热图式表格，同时显示系数和共同样本数；分时/日线随模式切换，缺失值采用中性灰并写明原因。
- 颜色不能作为唯一识别手段；图例、名称、样本和来源文字必须可见。

## 验收标准

1. 上证指数分时点位约为指数点位，不得出现 10 元级股票价格。
2. 八个指数卡片能在分时/日线间往返切换且无重复实例泄漏。
3. 搜索“银行”可加入真实市场板块，与科创 50 一起显示日线和相关性。
4. 快速切换窗口、模式和选择时，旧请求不能覆盖新选择。
5. 选择 1 项或第 9 项会被阻止并显示原因。
6. 接口失败、样本不足和休市状态均有可读说明，无模拟数据。
7. 桌面和窄屏下选择器、图例和矩阵均可滚动且不挤压页面。
