# ADR-003：由文稿证据与公司业务共同构建产业图谱

状态：Proposed（待规格审阅），并非已接入生产。
日期：2026-09-22。

## 背景

现有三栏是环节词匹配的展示；作者文稿关系在另一入口，不能回答公司业务、细分产业地位及关系证据。用户要求可拖动/展开、有梯队顺序的思维导图，并已确认产业地位与涨幅排序分离。

## 提案

1. 公司是唯一实体，业务/产品是产业分支的实体，证据支持的是有类型的边。公司多业务用统一身份的分支引用呈现，不重复建公司。
2. 梯队绑定细分业务、比较市场、时间及依据，不是全局公司标签；资料不足未评定。
3. 作者观点、正式资料、人工核验及行情指标分层。只出现同一文稿中的词语不能形成供货或主营事实。
4. 文稿分析按原文哈希和规范版本处理，允许零关系，新增质量与覆盖状态；新资料不覆盖旧证据。
5. 默认有序分层图，利用已安装绘图库能力按需展开；不引入图数据库，不在本阶段确认具体存储迁移。

## 比较过的方式

- 继续三栏：成本低，但不能表达业务、类型化关系和同领域梯队，无法满足本次需求。
- 默认力导向大网图：可展示交叉关系，但布局不稳定，不利于用户要求的先后次序，并增加大量节点时的计算负担。
- 有序分层图加选择式交叉边：能够先解释主题、业务、产品与公司，再按需查看交叉关系；作为待确认方向。

## 影响及约束

必须补足逐视频分析质量、全量概念覆盖和公司业务证据；仅重画前端并不能生成可信产业事实。现有 ChatGPT 人工协调不等于应用的无人值守 AI 连接。
