# ADR-006：升级定位保护与独立安卓自选颜色

状态：已实现，Windows 安装替换尚待实际验收。日期：2026-10-10（北京时间）。

## 背景

2026-10-09 的对话审查指出：安装目录旁的 runtime-location.json 可能被旧版卸载器移除；安卓分组仍是下拉框，没有可备份的分组色和股票覆盖色。只调整 CSS 无法解决升级丢定位、改名丢颜色或旧备份覆盖新设置。

## 决定

### Windows

- 保留现有侧置定位文件，并在安装器卸载旧版本前保存到 `%ProgramData%/WebStock/runtime-location.json`，再暂存到安装器私有临时目录；安装完成后还原侧置文件，兼容回退旧版。
- 读取旧版注册表 InstallLocation，不凭新的目标目录寻找旧配置。
- 两份配置不一致、无法备份/复制时中止升级。安装器采用保守的字节比较，格式不同也需人工核对；不静默选择其中之一。
- 安装版启动时严格验证两份配置及实际 webstock.db；侧置文件缺失可用稳定副本，损坏/冲突/数据库缺失则拒绝创建空库。开发版和便携版不读取全局副本。
- 配置副本不是数据库备份；此变更没有复制、删除或恢复生产数据库。

### Android

- 继续使用现有 SQLite `records` 表，新增 `watchGroups`、`watchStyles` 记录类型，不升级/重建数据库。
- 老分组按名称派生稳定 UUID；读取不改写自选。分组首次编辑后显式保存 ID。改名在一个事务里更新全部成员，保留颜色与 ID。
- `watchGroups`：`id/name/color`；颜色只能是 neutral/blue/violet/teal/amber/rose。
- `watchStyles`：`id` 为带市场前缀的证券身份，`color` 可为 inherit 或上述颜色，`primaryGroupId` 可选且须属于该股票。它仅是显示偏好，不改变证券、报价或账本身份。
- 股票颜色优先级：显式覆盖 → 当前选中且所属的分组 → 有效主分组 → 分组列表中的首个所属组 → 中性。移走或移除主分组成员时清理失效引用，保留覆盖色。
- 颜色只作用于名称、色点、名称侧边条和组标签；不覆盖报价涨跌、K 线、均线颜色。深浅主题分别定义可读色值。
- `/state` 返回上述两类记录；现有 `/record` 保存/删除，现有 `/backup` 导出并原子合并导入。旧备份缺少两类记录时不删除已有颜色；空分组保留，有成员的分组不允许直接删除。旧版 App 再次导出可能丢失它不认识的字段，不能承诺跨旧版往返兼容。

## 未采用

- 不把颜色只写 localStorage：无法随已有备份可靠迁移。
- 不把所有分时空点连起来：缺采/竞价过程缺源仍须明确。
- 不把全部蜡烛统一染成当天涨跌色：蜡烛按每根开收关系，整条分时线按最新有效点与有效昨收关系；均线保持独立颜色。
- 不通过放大价格轴留白容纳全部九转标记：独立标记层避让重叠，不改变 1–9、C1–C13 算法与事件，密集隐藏标签可缩放/逐点读数核对。
