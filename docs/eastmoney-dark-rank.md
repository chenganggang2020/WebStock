# 东方财富暗盘榜：盘中刷新与个股关联

## 已实现范围

“资金动量”顶部展示真实网页榜单。支持个股、行业、日期、30 条分页、手动查询、点击名称聚焦大字金额、暗盘活跃度和明暗净额符号比较。今日榜单在可见页面盘中每 60 秒检查；可取消勾选暂停。默认日期跟随交易日，手选历史日期后不自动改动。概念榜尚未完成实测，因此界面与 API 不开放。

个股详情、自选表、持仓表关联同源明盘/暗盘净额和活跃度。仅新增展示，不修改自选来源、持仓数量、成本或交易记录。

暗盘是供应商量化模型估算，不是官方资金统计、机构持仓或逐笔订单流。原资金动量、授权 Level-2、本地估算和快照回放保持分离。

## 本地接口

`GET /api/capital-flow/dark-rank?date=2026-09-17&scope=stock&page=1`

- date：真实有效的 YYYY-MM-DD 日期；按原日期查询，不悄悄改为最近交易日。
- scope：stock 或 industry；不允许重复/数组参数。
- page：1–1000 的整数，默认 1；页面依据提供方报告总数翻页，不自动全量抓取。
- 200：`{success:true,data}`；data 使用 `webstock.eastmoney-dark-rank/v1`，不含原始 raw 对象，新增 `cache.hit` 和 `cache.ttlSeconds`。
- 400：无效条件；429：两个不同查询已在进行；502：提供方失败/拒绝或结果校验不通过。对外错误不暴露内部异常或凭据，不提供其他资金源降级。

相同条件共享未完成请求，并缓存成功结果 60 秒，最多 32 页，仅存在当前进程内存中。失败不当作成功，也不将过期缓存作为新结果返回。前端仅在“相同日期、类型、页码”查询失败时保留自己上次显示的数据并标明“旧数据”；切换条件立即清除旧显示并使旧请求失效。

## 数据口径与实现决定

### 个股共享快照（2026-09-17）

- `GET /api/capital-flow/dark-session`：服务器北京时区及既有交易日历，返回 `dataDate`、`pollAllowed`。正常交易时段及 15:00–15:05 收盘补查；午休、休市、未知年份暂停自动刷新。现有日历只覆盖 2026 年，之后个股自动选日返回 503，不能按星期猜节假日。
- `GET /api/capital-flow/dark-stocks?codes=sh600487,sz000725`：1–200 个带市场前缀的 A 股代码；股票日期由服务端选择，盘前/休市返回明确标注的前一交易日。指数、ETF 不按同号股票匹配。未匹配单列 `missing`，不是零。
- 未核验单股过滤接口。实测网页后台支持 `NumPerPage=100`，500/1000 被拒绝。因此用顺序分页的共享内存快照，最多 60 页/6000 条、页间 250ms、总时限约 45 秒（加当前请求至多 10 秒）。只在页面需要时加载，全进程合并请求，成功缓存 5 分钟，失败至少退避 60 秒。
- 完整扫描后原子替换；某页失败/日期或总数改变时保留同日旧快照并标记 `stale`，无同日快照时返回 502。不会用昨日值填今日。金额缺失仍为空。
- 分页排序在盘中可能移动：按市场和代码去重，重复数、实际覆盖数均公开；即使条数齐全，`paginationSnapshotConsistent=false`，不能称为同一时刻的全市场快照。各股票保留其所属页采集时间。
- 浏览器每 60 秒检查当前视图；个股缓存约 5 分钟更新，榜单当前页 60 秒缓存。进入页面会先读取一次，即使收盘也允许手动查询；隐藏/最小化和离开相关视图时停止后续轮询。不是关窗后持续运行的后台采集器。
- 东方财富网页脚本 `main.79b98a58.chunk.js` 自身有盘中 5 秒轮询逻辑，但这不是其源数据延迟或外部服务 SLA 的保证。WebStock 不模仿逐秒请求，不称“交易所实时”。

- 来源固定为东方财富 GrayMarketRank 网页后台，不接收客户端指定 URL、令牌或文件路径，无新增依赖。
- 金额来自提供方元整数，内部保存整数分字符串，显示按元/万元/亿元四舍五入到两位小数。金额和空值的区分不依赖浮点计算。
- 暗盘活跃度直接展示提供方字段；未独立验证其分母和算法，不自定义解释。
- 同向/反向只比较明暗净额符号，没有“主力吸筹/出货”的身份或预测结论。
- `receivedAt` 是采集时间，不是假定的行情事件时间。未知提供方时钟保持未知，不伪造分钟曲线。
- 不将单页描述为全市场。分页期间可能变化；行业存在重叠，不将行业净额加总为全市场净额。

## 暂未实现

个股榜仍没有独立后台常驻采集或连续多日信号；未验证盘中跨整日持续可用性，非逐秒实时。未改持仓账本、自动荐股、产业链、抖音采集或实盘交易。

2026-09-17 新增的“板块资金轮动雷达”单独提供行业/概念后台采样、每日文件历史及 5/15/30 分钟采样差额排名。详见 `development/Sector_Rotation_20260917.md`。它不改变本页个股榜的查询和缓存机制；板块采样曲线不是供应商分钟行情或实际资金迁移图。

网页接口未公开正式对外合同，长期稳定性、配额与数据使用授权仍需确认。不能把按需榜单或板块后台采样的实现等同于全天候数据可用性已经验证。
