# 首页市场驾驶舱与科技产业链发现 V1

## 目标

首页首先回答四个问题：大盘怎样、市场是否普涨、热点在哪里、资金数据是否可信。产业链发现页回答：某个科技主题由哪些环节组成，哪些本地股票被现有证据关联到这些环节，还缺什么证据。

本阶段只交付网页版，不制作安装包；不自动交易，也不把筛选结果表述为投资建议。

## 首页驾驶舱

首页复用现有公开数据接口，按以下顺序展示：

1. 主要指数：指数名、点位、涨跌幅、成交额和更新时间。
2. 市场温度：上涨、下跌、平盘、涨停样本、大跌样本、成交额和样本覆盖范围。
3. 板块轮动：领涨、落后和供应商资金净额靠前的板块；行业与概念不得静默合并。
4. 资金证据：必须显示来源、观察时间、样本范围和降级状态；不可用显示“暂不可用”，不得用 0 代替。
5. 我的关注与重要事件：保留现有自选、持仓、风险和资讯能力，但不抢占首屏市场判断区。
6. 数据健康：保留并降低视觉权重，异常时再突出。

首页资金文案统一使用“供应商分类资金”或“主动买卖估算”，不得称为交易所确认的机构净流入。北向资金不展示伪实时净买入。

## 产业链自动归纳

### 输入

- 本地股票代码与名称；
- 本地 `stock_search_index` 中由 F10 资料同步的行业、主营、板块和标签等字段；
- 知识库来源的标题、标签、关联股票、关联板块和正文证据；
- 后续可接入的公告、公司官网、定期报告和授权行情/研究数据。

### 分类规则

产业链模板只定义主题别名和环节关键词，不直接硬编码“推荐股票”。V1 支持至少：半导体、AI 算力与 CPO、PCB 与先进封装、机器人、新能源电池。

标准环节为：

- `materials`：原材料与关键耗材；
- `equipment`：生产、检测和制造设备；
- `components`：核心器件与零部件；
- `manufacturing`：加工、制造、封装与系统集成；
- `applications`：下游应用与需求侧。

### 证据与状态

每条股票关系必须包含：`chain`、`stage`、`stockCode`、`stockName`、`confidence`、`evidence[]`、`observedAt`。

- `confirmed`：至少有一条明确绑定股票代码、带原始链接和观察时间的主营/F10/公告/正文证据，并在非否定语境中同时命中主题和环节；
- `candidate`：行业、概念、程序标签或正文命中，但股票绑定、来源链接或暴露路径仍不完整；
- `unavailable`：没有可用证据。

证据包含稳定编号、来源类型、标题、原始链接、发布日期或观察时间，以及简短匹配理由。没有证据的股票不得进入 `confirmed`；名称相似、模型常识、硬编码主题标签、程序文本匹配得到的股票关联都不得充当确认性证据。“没有、未涉及、不生产”等否定或澄清表述必须作为反证/待核验信息，不能升级为确认关系。

### 查询与呈现

用户可以输入自然关键词，例如“半导体材料”“CPO 设备”“机器人零部件”。程序先识别产业链和环节，再返回：

1. 产业链环节图；
2. 已确认关联；
3. 待核验候选；
4. 缺失证据与下一步需要采集的资料。

结果是研究候选池，不是最终荐股。后续排序必须把暴露证明、时效、来源质量和多来源一致性与行情热度分开。

未知自然查询不得静默扩展到全部产业链；非法显式产业链或环节筛选返回参数错误。只有用户明确输入“全部”时才允许全量归纳。

## 验收条件

- 首页刷新后能看到指数、宽度、板块和资金来源状态；接口失败时页面仍可使用且不伪造零值。
- 产业链纯逻辑测试覆盖主题识别、环节识别、证据分级和空数据。
- 产业链接口能从本地知识来源和股票资料自动生成结果，并保留来源证据。
- 页面支持搜索产业链、切换环节并查看证据；没有结果时明确提示如何补充资料。
- 针对性测试通过，并在 `http://127.0.0.1:3000` 完成可视检查。
