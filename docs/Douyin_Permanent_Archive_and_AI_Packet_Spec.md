# 抖音永久存档、增量更新与 AI 数据包规格

## 目标

WebStock 先建立研究对象当前公开可见作品的完整本地清单，并在可取得媒体时永久保存原始媒体；后续按增量更新运行。远端作品不可用或删除时，本地数据库、逐字稿和已完成媒体归档继续保留，只更新远端可用状态。

研究资料可按“最近 N 条”“指定时间段”“全部”生成统一 AI 分析数据包。数据包以可核验的说话内容为核心，清楚区分本地 ASR 逐字稿、页面可见文字、来源元数据和程序提取结果，不把摘要或模型推断写成本人原话。

## 不可变规则

1. 已完成归档的媒体文件不参与自动删除。程序只可清理下载失败或中断产生的 `.part` 临时文件。
2. 远端不可用、作品下架或删除只修改 `availabilityStatus`；不得级联删除本地观察记录、互动快照、逐字稿或媒体文件。
3. “内容更新”由稳定的实质内容指纹判断。`observedAt`、`lastSeenAt`、`detailCapturedAt`、签名媒体 URL 和重试时间不进入指纹。
4. 每次主页发现的所有可识别作品先轻量入库，再安排详情和转写；不能只为本轮前几条建立数据库记录。
5. 详情队列按新发现优先、最久未检查优先和失败退避运行。失败或待媒体项目不能永久占满队列、饿死较老作品。
6. AI 数据包不得静默截断。若数据量过大，界面必须明确显示条目数和字符数，再由用户决定复制或缩小范围。

## 两阶段采集

### 完整存档

- 从研究对象主页开始，分批滚动公开可见作品列表，按作品 ID 去重。
- 每批发现后立即轻量入库，保存作品 ID、公开来源 URL、标题、发布时间（若可见）及首次/最后发现时间。
- 详情、媒体归档和 ASR 采用有界队列继续处理；任务可中断并从数据库状态继续。
- 连续若干批没有发现新作品，或达到公开页面/风控/登录边界时结束本次扫描，并如实记录边界，不能宣称取得不可见作品。

### 增量更新

- 定时读取主页最近作品，先比较作品 ID 集合和稳定指纹。
- 新作品立即进入详情与归档队列。
- 已有作品仅在到达复查时间或页面稳定字段发生变化时重新采集详情。
- 失败使用指数退避；近期活跃作品复查较快，长期未变化作品逐步降低频率。

## 永久媒体归档

- 稳定目录：`WebStockData/media-library/douyin/`。
- 下载使用同目录 `.part` 临时文件，完整下载、计算 SHA-256 后原子重命名。
- 数据库记录本地路径、SHA-256、字节数、MIME、归档时间和来源作品 ID。
- 后续 ASR 优先复用本地媒体；即使签名 URL 过期或远端作品不可用，也能从本地重新转写。
- “删除资料”只能删除研究索引关系；媒体归档删除必须是单独、明确且带目标确认的人工操作，本期不提供自动删除。

## AI 分析数据包

筛选模式：

- 最近 N 条：按发布时间从新到旧选择，N 由用户填写。
- 指定时间段：包含起止时间边界内的作品。
- 全部：包括当前筛选研究对象的全部视频记录，不静默截断。

每条记录至少包含：

- 研究对象、作品标题、发布时间、原始公开 URL、远端可用状态；
- 证据类型：`本地 ASR 逐字稿`、`页面可见文字` 或 `无可用原话`；
- 完整逐字稿（优先）或明确标注的页面文字；
- 可核验互动指标及其观察时间；
- 股票代码/主题只能作为“程序提取标签”单列，不混入原话。

数据包不得包含短时效签名媒体 URL、本地绝对路径、登录信息、Cookie 或程序自动生成的投资结论。输出同时返回条目数、字符数、筛选范围和缺少逐字稿的警告。

## 验收条件

- 仅刷新采集时间不增加“实质更新”计数；正文、逐字稿或稳定互动值变化会增加。
- 主页发现 20 条但本轮详情上限为 8 条时，20 条都已存在本地数据库，剩余 12 条保留队列状态。
- 一个连续失败的作品不会阻止其他历史作品获得详情采集机会。
- ASR 成功后媒体文件仍存在；第二次处理同一作品可在没有远端 URL 时复用本地文件。
- 远端标记为删除后，本地媒体、逐字稿和观察记录仍可用于数据包。
- 最近、时间段和全部三种数据包的数量、顺序和证据标注可由测试复现。

## 验证命令

- Node 回归：`npm test`
- 前端回归：`npm run test:frontend`
- 量化回归：`npm run test:quant`
- Windows 打包：`npm run dist:win:all`

## 调度决策：更新触发自动采集

- 每 10 分钟定时任务自动加载创作者主页并核验身份；发现新增作品、实质变化或仍待完成的同步项后，直接进入正式导入和有界处理队列。
- 自动队列会保存作品观察、打开目标详情页、下载并永久归档可验证媒体，并在需要时启动本地 ASR；无需用户再次手动确认。没有待处理项时不打开详情页或下载媒体。
- 普通手动同步仍可立即触发同一自动采集链路；“全量扫描、下载并转写”用于遍历全部未完成历史视频，是独立的高成本补全任务。
- 全量队列以作品记录中的永久媒体路径和完整 ASR 状态为断点。已完成项跳过；中断后再次启动时只处理未完成项。
- 全量任务不受普通单轮详情/转写配额限制，但仍严格串行处理当前作品、保留登录和身份校验、CDN 白名单、临时文件及原子发布边界。
- 完成条件必须同时满足：作品为视频、ASR 状态为 complete、逐字稿非空，并存在永久本地媒体路径。
