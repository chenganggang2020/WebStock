## 建议顺序（尚未实施）

1. 固定几何合同：头部、读数、价格、量、副图、X/Y轴、状态各有独立保留区域；同窗口/模式切换证券时位置不变。响应式只由窗口宽度/字体/DPI变化触发，不能由文本变化触发。
2. 状态与数据分离：框架常驻；同证券刷新不清空已有图；没有数据时显示固定骨架和简短状态，保持数据真实性。异常完整详情折叠保留。
3. 统一交互：拖动读数与拖动历史区分，支持滚轮缩放、Home恢复、键盘读取；刷新不夺走用户历史位置。优先主看盘与全球页，再覆盖其余图表。
4. 数据更新审查：检查报价与K线的源时点、页切换、去重、取消、缓存保留和失败重试。缺数据是源限制、解析拒绝、没调度还是没重绘，必须分别给证据。
5. 验收：专项单测/真实控件几何测试/真实来源/安装版手工交互分层记录。每个编号独立写未做、已实现、已测试、实机通过、已同步状态，不以一套测试代替全程序完成。
