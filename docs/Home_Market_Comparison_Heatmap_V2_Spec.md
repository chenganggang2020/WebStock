# 首页市场对比与板块热力图 V2

## 目标

把顶层“行情”并入“首页”，让首页直接回答三个问题：主要指数走势是否一致、哪些指数正在分化、板块强弱和资金集中在哪里。个股分时与 K 线仍保留，但作为首页内部的个股详情模式，不再占用单独的顶栏入口。

本阶段先交付网页版，不制作安装包；不自动交易，也不把相关性或热力图表述为买卖建议。

## 导航与页面结构

1. 顶栏只保留“首页”，删除独立“行情”按钮。
2. 首页默认展示市场总览；从左侧股票、自选、持仓或榜单进入个股时，打开内部个股详情，顶栏仍高亮“首页”。
3. 个股详情的返回按钮回到首页市场总览。
4. 保留现有 `switchMainView('market')` 作为内部兼容路由，避免破坏既有双击选股和各模块的详情入口；它不再是用户可直接选择的顶层页面。

## 指数走势与相关性

### 数据契约

- 为指数建立独立的显式市场代码映射，不能复用按六位代码首位推断股票市场的通用 K 线接口。
- 覆盖上证指数、深证成指、创业板指、科创 50、沪深 300、中证 500、中证 1000、上证 50。
- 新接口：`GET /api/market/index-history?window=60`。
- `window` 仅接受 20、60、120，默认 60 个交易日。
- `series` 每条序列包含指数标识、名称、显式供应商代码、日期与 OHLCV 原始点；顶层 `comparison` 保存共同交易日及归一化值，顶层 `correlation` 保存由共同交易日对数收益率派生的相关矩阵与样本数，顶层 `source` 记录该批数据的统一来源。不得用股票行情冒充指数行情。
- 供应商失败时返回明确的部分可用或不可用状态，不能生成模拟曲线。

### 比较方法

1. 叠加走势使用共同窗口内每条指数的第一个有效收盘点归一化为 100，解决不同指数点位量级不可直接比较的问题。
2. 相关性使用共同交易日上的日对数收益率计算 Pearson 相关系数，不使用指数点位水平直接计算。
3. 每一对指数至少需要 20 个共同收益样本；样本不足、零方差或无有效数据时显示“样本不足”，不显示 0。
4. 相关性只表示同涨同跌程度，不表示因果关系。

### 展示

- 每张指数卡片包含点位、涨跌幅、成交额和最近 20 日迷你走势。
- 大图默认叠加最近 60 个交易日，可切换 20 / 60 / 120 日；纵轴为“起点=100”。
- 相关性矩阵与叠加图使用同一时间窗口，并显示共同样本数。
- 正相关和负相关必须同时用数值、文本和颜色表达，不能只依赖颜色。

## 板块强弱与资金热力图

采用 Treemap（市场热力图）：矩形面积表达规模，颜色表达方向和强度。

### 默认模式：板块强弱

- 面积：板块成交额。
- 颜色：当日涨跌幅；按 A 股习惯，红色为上涨、绿色为下跌、中性为灰色。
- 行业与概念使用独立标签，不静默混合排序。

### 资金模式

- 面积：供应商分类资金净额的绝对值。
- 颜色：资金净额正负及强度。
- 标签显示带符号的资金净额，并明确“供应商分类资金，不是交易所逐笔资金真值”。
- 只有涨跌幅而没有资金字段时，强弱模式仍可用，资金模式显示不可用；不得以成交额或 0 冒充净流入。

### 可读性

- 方块至少显示板块名和当前指标；过小方块通过悬浮提示补全。
- 图例明确说明面积和颜色的口径。
- 数据来源、抓取时间、降级状态常驻图表下方。

## 验收条件

- 顶栏没有独立“行情”，进入个股详情时“首页”仍高亮，返回后恢复首页总览。
- 八个指数使用显式指数代码获取历史数据，`000001` 不会被解析为平安银行。
- 20 / 60 / 120 日归一化叠加图与收益率相关性矩阵能从同一批历史数据渲染。
- 日期对齐、归一化、相关性、样本不足和恒定序列均有自动化测试。
- 行业/概念热力图支持强弱与资金模式，面积与颜色口径可见，缺失资金不造数。
- 完整自动化测试通过，并在 `http://127.0.0.1:3000` 完成桌面和窄窗口可视检查。
