# WebStock 批量策略研究规格

## 目标

在现有“AI研究”页增加一个只读研究工具。用户可用明确的规则卡批量检查均线参数，并看到滚动样本外结果和参数稳定区。该功能不连接券商、不生成委托，也不把历史收益写成投资建议。

## 第一阶段范围

- 股票池仅保留沪深主板普通 A 股：`000/001/002/003/600/601/603/605`。
- 排除名称含 `ST`、停牌/无成交日，以及在窗口开始前历史不足的证券。
- 策略固定为“短期均线上穿长期均线后，下一交易日开盘买入；下穿后，下一可成交交易日开盘卖出”。
- 参数卡支持多组短期、长期均线，自动生成所有 `短期 < 长期` 的组合。
- 单次最多 64 组有效参数；全市场数据默认按首折训练期覆盖率和成交量选择最多 600 只主板样本，防止任务无上限占用资源。
- 执行模型记录 T+1、100 股整数手、涨跌停无法成交、佣金、最低佣金、印花税和滑点。
- 使用互不重叠的滚动样本外区间，完成至少 3 折后才允许标记“稳定区”。
- 同时展示最佳、最差和稳定参数区域；“最佳”仅表示当前历史样本外排序最高。
- 结果保存到量化工作区，保留数据清单哈希、规则、费用假设、折叠区间和警告。

## 明确不做

- 不接收自然语言并自动生成任意代码；第一阶段使用可审计的规则卡。
- 不自动买卖、不调用交易接口、不保存券商凭证。
- 不声称回测通过等于未来盈利；公开未复权数据只标记为探索性研究。
- 不在本阶段扩展到择时、选股、组合优化等其他策略家族。

## 验收标准

1. 主板过滤有单元测试，创业板、科创板、北交所和 ST 不会进入结果。
2. 涨停买不进、跌停卖不出、T+1 和费用模型有确定性测试。
3. 少于 3 个样本外窗口时拒绝生成“稳定”结论。
4. 结果契约包含 `automaticTrading: false`、执行假设、全部参数和逐折证据。
5. API 只能启动研究任务和读取结果，没有订单相关路径。
6. AI研究页能启动任务并区分稳定、观察、淘汰参数。

## 第二阶段：受控中文规则与多策略研究

### 目标

在第一阶段的同一只读研究链路中增加本地中文规则解析，以及 MACD、RSI、放量突破三类策略。中文只负责生成可预览、可修改的结构化规则卡，不生成或执行任意 Python/JavaScript 代码。

### 支持的策略家族

- `moving-average-crossover`：短期均线上穿长期均线入场，下穿离场。
- `macd-crossover`：MACD 线上穿信号线入场，下穿离场；参数为快线、慢线和信号线周期。
- `rsi-rebound`：RSI 从超卖阈值下方向上穿越时入场，到达退出阈值后离场；参数为 RSI 周期、超卖阈值和退出阈值。
- `volume-breakout`：收盘价突破此前 N 日高点且成交量达到此前 N 日均量倍数时入场，收盘价下穿 N 日均线时离场。

### 中文解析边界

- 解析由本地确定性规则完成，不调用外部 AI，不读取账号历史。
- 只识别上述四类白名单策略和有限数字参数；无法识别时返回错误，不猜测策略。
- 解析结果必须显示策略家族、入场规则、退出规则、参数组合数、默认值来源和 `automaticTrading: false`。
- 用户点击“运行”时提交结构化规则卡；服务端再次校验，不能只信任浏览器解析结果。

### 资源与结果边界

- 各策略单次仍最多 64 组参数，默认最多 600 只训练期流动性样本。
- 四类策略共用主板/ST过滤、滚动样本外切分、费用、T+1、涨跌停、停牌和整数手模型。
- 结果参数使用通用 `label + settings` 表达；旧均线结果仍可读取。
- 历史最佳、最差、观察、稳定和淘汰的含义不变；平均样本外收益不为正时不得标记稳定。

### 第二阶段不做

- 不允许任意公式、任意代码、券商连接、委托或自动加入持仓。
- 不在本切片加入组合优化、机器学习选股或每日自动候选。
- 不把中文语句解析成功等同于策略有效。

### 第二阶段验收标准

1. 四类中文示例均可转换为结构化规则卡，含糊或不支持的文本会被拒绝。
2. MACD、RSI、放量突破的参数网格、信号时序和最多 64 组限制有确定性测试。
3. 新策略复用第一阶段成交模拟，不复制或绕过 T+1、费用和涨跌停逻辑。
4. 新结果通过契约校验，旧均线结果继续通过契约校验。
5. 页面能预览解析结果、运行所选策略并以通用参数标签展示结果。
6. API 与结果仍明确 `automaticTrading: false`，不存在订单路径。

## 第三阶段：每日全市场研究候选与多策略比较

### 目标

把四类受控策略串成一条只读的每日研究流水线：在同一份已校验数据上依次完成参数稳定性研究，比较各策略的样本外证据，并把最近一个收盘日触发的信号合并成每日候选池。候选是下一交易日开盘前的人工观察清单，不是推荐、委托或持仓。

### 每日流水线

- 固定依次运行均线、MACD、RSI 超卖反弹和放量突破，四步共用同一数据集、截止日、费用与滚动窗口。
- 页面提供手动运行；程序运行时在北京时间工作日 09:05 后每天最多自动尝试一次。
- 自动运行只选择 `requested >= 1000` 的本地全市场数据集；数据截止日距当前日期超过 7 天时阻塞并提示先同步全市场，不回退到试跑数据。
- 定时任务已运行、正在运行或当天已完成时不得重复创建；手动运行仍允许用户显式选择数据集。
- 数据同步仍使用现有显式“同步全市场”任务。本阶段不在后台重新下载多年全市场历史，避免重复下载和程序卡顿。

### 候选与比较规则

- 参数稳定性仍在首折训练期选出的最多 600 只流动性样本上评估。
- 只有标记为 `stable` 或 `watch` 的参数可以产生候选；被淘汰参数和单纯“历史最佳”不得进入候选池。
- 全市场信号扫描最多使用证据排序最高的 12 组 `stable/watch` 参数，并披露符合门槛参数总数、实际扫描数和是否截断，避免每日任务失控。
- 候选扫描覆盖数据集中所有历史充足、非 ST 的沪深主板证券，不受 600 只回测样本上限影响。
- 信号只使用截止日及以前数据；`signalDate` 为最近收盘日，`earliestObservation` 明确为下一可成交交易日开盘。
- 多策略比较只合并同一 `datasetId + asOf` 的最新四类结果。缺少策略时标记 `partial`，不得伪装成完整共识。
- 候选排序只使用可解释证据：稳定策略家族数、观察策略家族数、家族共识数、样本外正收益窗口占比与股票代码；不使用热度或虚构综合分。
- 每个候选保留触发策略、参数、稳定级别和样本外指标；最多展示 200 只，同时报告总触发数与截断状态。

### 边界

- 不写入自选、持仓或同花顺，不连接券商，不产生买卖按钮。
- 不把多个弱策略的重叠解释为可靠信号；页面同时显示反证、数据新鲜度和缺失策略。
- 公开当前成分、未复权日线仍是探索性证据，不能升级为正式投资结论。

### 第三阶段验收标准

1. 四类研究结果包含可审计的最近信号候选，且未来行变化不会改变历史信号。
2. 被淘汰参数不能产生候选；候选扫描股票数与回测限流股票数分别披露。
3. 比较器拒绝混合不同数据集或截止日，并对缺失策略显示 `partial`。
4. 定时决策在北京时间工作日 09:05 后每日最多运行一次，旧全市场数据会被阻塞。
5. API、任务和页面始终显示 `automaticTrading: false`，不存在自选写入或交易路径。
6. 单元、API、量化和真实浏览器验收全部通过。
