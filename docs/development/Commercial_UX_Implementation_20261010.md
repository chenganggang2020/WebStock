## 本轮完成

1. Windows：稳定定位副本、安装前保存/冲突阻断/安装后还原。21 项隔离文件系统测试通过，NSIS 钩子编译通过；未执行本轮安装器。
2. 安卓：分时整线按最后有效价相对有效昨收红涨绿跌；无有效基准或持平用中性色。均价保持独立颜色，真实缺口不连接。
3. 安卓 K 线：有副指标时主图占可绘制高度 65%，量能与指标仍共用时间轴；蜡烛宽度 68%、上限 14px；九转标记独立布局，避免用过大轴留白压扁价格。所有算法和完整事件保留，密集标签避让，可用缩放、逐点读数和解释查看。
4. 修复实测横屏故障：App 提前 resize 后，ResizeObserver 误以为尺寸无变化，仍沿用竖屏像素网格，成交量被挤出画布。改为比较最后布局尺寸，旋转后重新布局所有面板。
5. 安卓自选分组改为直接可点、自动换行的按钮，不再使用隐藏分组的下拉框。名称/颜色编辑、新建空分组、股票单独覆盖色和主分组选择接入真实本地 SQLite；移出组和修改备注集中在股票行的“···”编辑入口。
6. 桌面跨市场缩略图和分时详情增加方向色，保留中性/未知与来源时间，不混淆指数、CFD、汇率。
7. 保留既有五入口、主页返回规则、市场前缀身份、切股周期、历史缩放位置和断网缓存。没有改为浏览器历史返回。
