# 导航与阅读工作区修复

## 范围和验收

- 资金只保留顶层六个入口：个股资金、明暗盘、板块轮动、历史回放、ETF/期货盘中、日终基准。内部不再重复；标题、选中态和刷新后的页面一致。
- 证据库成为独立视图，不再与 AI 研究共用左侧研究功能菜单。保留原有数据和接口。
- 证据库使用可搜索的紧凑资料列表，右侧提供原文阅读、证据分析、录入编辑。标题只移除展示前缀，不修改存储原文；技术标签放在溯源详情。
- 新闻点击后在右侧读取公开网页正文。摘要与正文明确区分；无法提取时保留摘要并说明原因。外部原文入口仅作核对备用。
- 不改采集、交易、数据库身份和业务历史，不启动付费 AI 分析。旧运行实例不强制结束。

## 接口和安全边界

新增 GET /api/news/article?url=...：仅支持明确白名单的新浪财经、东方财富新闻 HTTPS 页面，禁止用户信息、非标准端口、私有地址与跨白名单重定向。复用现有受限 DNS/固定地址 HTTPS 请求器，限制响应大小、总超时、重定向、并发和缓存数量；只返回纯文本段落，不传递源站脚本。暂不支持的来源、登录/付费内容返回明确不可用状态，不补写正文。

本机 TUN DNS 返回 198.18/15 虚拟地址，经真实请求证实导致 SOURCE_DNS_PRIVATE。仅对此特定虚拟段使用固定 Cloudflare HTTPS DNS 重新查询白名单域名，再按原有公网检查并绑定真实地址；普通内网结果依旧拒绝。无需关闭代理或改变系统配置。HTTPS DNS 本身有 4 秒超时、32 KiB 上限、禁止重定向，整体读取期限 12 秒。

## 实施顺序

1. 先加导航与阅读回归，再拆分视图。
2. 正文提取服务与失败/安全测试，再接右侧阅读器及迟到响应保护。
3. 证据列表和详情适配，再做真实本机数据只读浏览器验收。
4. 全量回归、打包检查；桌面旧实例与新包分开报告。
