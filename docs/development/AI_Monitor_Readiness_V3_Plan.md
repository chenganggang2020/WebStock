# 模拟运行准备与交接修复（2026-09-07）

## 本轮范围

用户同意修复下一步优先项：运行准备检查、模型交接联调和独立模拟模式。只改纸面账户相关流程，不下实盘委托，不代替用户登录，不重置真实/模拟持仓，也不改模型密钥或公网配置。沿用现有 `holdingsSyncRequired` 字段，旧账户模式不自动切换。

## 分步契约与验收

1. 修通模式开关：独立模式不读取或传出真实持仓；参考模式仍要求最近 5 分钟完整持仓。准备记录固化模式，切换模式使未使用准备及待成交意图失效；历史建议、成交、净值保留。验证：缺失同花顺时独立可准备/回填，参考模式拒绝；切换后旧凭证不能复活。
2. 候选池和准备检查：独立模式只评估明确加入的候选及已有模拟持仓；提供有上限的手动代码添加，不把候选自动买入。检查账户、时段、持仓、股票池、行情、模型配置和调度，区分配置存在、需外部回填、实际调用成功。验证：空池/休市/旧价/缺密钥分别可见，检查不能生成建议或成交。
3. 修复交接错误被当成功：服务端拒绝回填时保留窗口和文本，不显示关联成功；成功后才存本地成功历史。加入明确的输入截止/过期时间和校验结果。验证：失败、纠正后重试、观望、过期和幂等。
4. 完整 Node 回归、桌面与窄屏实页验证、独立便携包启动检查；源码与生产程序分开验证。真实模型未接通则报告未完成现场联调，不用测试返回值代替。

## 边界与后续

这是前向模拟，不是已验证策略绩效。成交量约束、分红除权全生命周期、长期全量回撤/基准对照和 iPhone 真机配对另行实施。本轮不改交易费用或交易所规则。

## 实现与审查记录

- 模式设置沿用旧字段，接口只接受布尔值。界面每次只发送实际变更的设置，请求期间禁用对应控件，避免切换模式后其他开关用旧缓存覆盖模式。
- 独立模式不调用真实持仓读取，不把真实持仓送入提示词；只合并用户明确添加的候选和已有模拟持仓。手动代码添加为增量，最多 50 只；新候选权重为零，不自动创建持仓或成交。
- 运行准备区逐项展示账户、交易时段、真实持仓、候选池、证券行情、模型通道和调度。普通状态读取不抓行情，主动检查不产生建议、准备凭证、订单或成交。等待行情期间账户、候选、模式、设置或交易时段变化时，结果作废；页面已加载新状态时，旧请求也不能覆盖它。
- 参考模式在准备开始、行情返回及实际收到回复时核对持仓新鲜度；准备有效期不晚于持仓观察时间加 5 分钟。避免生成时持仓已过期、或显示可恢复但实际上不能回填的提示词。
- 可恢复尚未使用且未过期的提示词；显示原始输入截止和回填有效期。模拟提示词按服务器原文显示和复制，不叠加普通研究的风格指令。
- 回填必须等待服务端接受后才显示成功和存本地成功历史。失败保留输入和窗口；重复点击仅提交一次。无效 JSON 保存原始审计，但不消耗准备凭证，允许有效期内更正。
- 同一调度时段最多一条有效建议。同原文且仍通过校验的重复提交幂等；不同回复或坏回复保留为未采用审计，不再返回旧建议冒充本次成功。旧有效建议、历史成交和净值不被新失败覆盖。
- 测试代理先复现失败，再修复；独立只读审查最终重跑相关 66 项全部通过，已报告的同槽误成功、界面旧值覆盖及持仓过期边界均闭合。未调用真实模型，也未用测试返回值代替实际模型表现。

## 使用顺序

1. 退出正在运行的旧 WebStock，再打开与原 `WebStockData` 同目录的新 V3 便携版。不要同时让新旧程序接管同一数据库。
2. 进入“AI研究”的盯盘模拟区。没有可验证同花顺持仓时，明确选择“独立模拟”；需要真实持仓作为风险参考时保持参考模式，并完成最近 5 分钟只读同步。旧账户不会自动变更模式。
3. 展开候选股票池，明确填写需要评估的股票代码；点击“检查运行条件”。盘中条件通过后才生成新判断。
4. 已配置有效直连时可调用模型；否则复制原始提示词给外部模型，使用结构化 JSON 回填。“自动已启用”不表示模型已经接通。关闭交接窗口后，可在未过期时点击“继续待回填”。
5. 首次真实模型回复、盘中模拟成交和长期净值仍需实际运行验证。软件只做纸面模拟，不下实盘单，不保证盈利。
