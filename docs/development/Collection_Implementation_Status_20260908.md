# 采集与资料库修改：实现及验收边界

日期：2026-09-08。用户已批准实现。未覆盖旧便携程序，未操作生产数据库或真实交易。

## 本轮已实现

- SQLite UTC 时间规范化；详情与转写失败独立退避，五次失败暂停自动重试。
- 自动任务仅处理标记为新增、实质变化或其未完成重试的视频；历史归档单独运行。普通任务和单视频任务共用串行队列。
- 单视频补采、下载、重新转写、更新可见评论入口；已有本地归档的转写不访问作者主页。
- 成功转写替换时保留旧文本及 ASR 元数据；失败或无语音结果不覆盖已有成功转写。
- 评论累积保留、旧响应不覆盖新记录、历史版本、分页和完整导出恢复。采用兼容的 versions_json 增量列，避免重建现有评论表。
- 视频封面采集与本地缓存、受路径约束的本地视频播放接口及页面播放器。
- 作者主页身份去重、同名不同作者区分、可视化添加及编辑、自动任务初始化。
- Windows 打包版的可选登录后台启动设置与状态回读；关闭窗口隐藏到托盘机制继续沿用。
- 页面每 15 秒独立读取本地持仓快照，不再因行情未变化或原持仓为空而漏掉新增持仓。

## API 与边界

- GET /api/portfolio/holding-snapshot：本地账户、持仓、估值及版本；不触发 OCR 或外部行情请求。
- GET /api/expert/channels/:id/observations/:observationId/media：只提供该记录对应、归档根目录内的 MP4。
- GET 同前缀 /cover：HTTPS 白名单封面下载、大小限制与缓存。
- 评论接口支持 limit/offset、total/hasMore；远端缺失不触发本地删除。
- 桌面单视频 IPC 检查主窗口调用者、视频身份和作者身份；不会绕过平台登录限制。
