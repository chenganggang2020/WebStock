# 压力判断与价位标签避让

## 范围与依据

补充K线压力/支撑/自选参考位的解释与展示，不新增行情请求、数据库写入或交易动作。历史高低点聚类和强弱算法保持不变：最多120根历史样本、左右各2根确认局部拐点；强为至少3次触碰且至少2次反向收盘，中为至少2次触碰，弱为1次触碰。容差沿用后端返回值，不根据屏幕像素重算价格。

标签展示真实价位、已有强弱等级及当前载入K线最新价格相对观察区的位置。点击标签可核对价差百分比、容差区间、行情日期、日线参考日期、来源依据和失效条件。未完成K线明确显示“现价/待收盘”；区上或区下仅是相对位置，不宣称有效突破。手工备注、自选预警及缺少依据的旧记录不自动升级为已验证压力。

## 展示规则

- 真实水平线和观察区不移动，仅把文字移至图表右侧独立栏，按原始价格高低排列并保留同色引线。
- 标签高34px、间距38px；容器不够高时完整保留为可滚动列表，不缩小文字、合并不同价位或静默隐藏。
- 支撑与压力最近触碰的圆形标记分别向下、向上偏移，数据坐标保持原样。
- 开关“图上提示”保留自选价位；重复刷新不叠加重复标签。没有价位时恢复原图表右边距。
- 缩放与尺寸变化重新排布；普通十字光标刷新不重建标签。复用图表前移除旧的标签及事件监听。
- 依据使用纯文本DOM展示，不把来源文字插入HTML。没有新增依赖。
