# 九转计算说明与周期边界

本次按用户要求补充可核对的计算方法，不改变九转算法、不新增分时信号、不改变采集任务。

- 图表上方 `nineTurnMethod` 提供可折叠规则，日线和分时页面均可阅读；展开高度受限，避免挤占整个图表。
- 日线逐根比较 `C[t]` 与 `C[t-4]`，严格大于或小于时分别连续计数；相等或显式无效窗口归零，反向从1开始。比较窗口内先前4根须有效且已收盘。
- 当前规则至少需13根有效日K才能首次计到9；超9不重复绘制。当前未收盘K（含北京时间当日15:01前）淡显，不能当作确认事件。
- 每个1–9的悬浮依据展示本根实际比较价格、前第4根日期和收盘价；未收盘价格明确称为“暂定价”。
- 9是观察标记，不是必然反转或交易指令。现有模型未实现完整TD Sequential的13倒计数、完善形态等附加条件；不能仅删除“简化”字样就宣称完整版。
- 分时九转尚未接入。本次只解释可按固定分钟K周期计算，未把日线计数或5秒/30秒报价直接套给分时。若未来新增，需单独确定分钟闭合、缺口、午休/跨日衔接和历史预热策略。
- 官方方法背景：https://demark.com/tradingview/ 。官方说明不构成本程序已实现完整指标的证明。

验证：新增3项测试先失败后通过；连同既有图表、计数与历史核对测试共60项通过。浏览器使用本地隔离样例与真实前端模块，不读取生产持仓或触发采集。打包验证与正式程序替换须单独报告。
