# 九转计算说明与周期边界

按用户要求展示可核对的计算方法，并接入1分钟分时九转。沿用日线基础计数规则，不改变采集任务。

- 图表上方 `nineTurnMethod` 提供可折叠规则，日线和分时页面均可阅读；展开高度受限，避免挤占整个图表。
- 日线逐根比较 `C[t]` 与 `C[t-4]`，严格大于或小于时分别连续计数；相等或显式无效窗口归零，反向从1开始。比较窗口内先前4根须有效且已收盘。
- 当前规则至少需13根有效日K才能首次计到9；超9不重复绘制。当前未收盘K（含北京时间当日15:01前）淡显，不能当作确认事件。
- 每个1–9的悬浮依据展示本根实际比较价格、前第4根日期和收盘价；未收盘价格明确称为“暂定价”。
- 9是观察标记，不是必然反转或交易指令。现有模型未实现完整TD Sequential的13倒计数、完善形态等附加条件；不能仅删除“简化”字样就宣称完整版。
- 分时九转已接入“1分钟公开行情”：使用来源明确标识为60秒的分钟价格序列，逐根显示1–9。5秒/30秒报价、降级5分钟及合成数据不计算这套1分钟指标，并显示原因。
- 分时按北京时间判断分钟闭合：当前分钟淡显并标“未收盘”，下一分钟利用已有刷新流程重算；来源明确标记为未完成时仍不确认。未增加行情请求、计时器或数据库写入。
- 分时只使用选定交易日，不跨日延续。开盘竞价不参与；午休跳过，下午继续上午计数。缺失分钟占位并中断比较，重复时间去重；标为`bar-end`的来源不补出09:30/13:00这两个不存在的分钟收盘点。历史行情使用同样规则，不能把当天尚未到达的分钟当成历史。
- 官方方法背景：https://demark.com/tradingview/ 。官方说明不构成本程序已实现完整指标的证明。

验证：原计算说明阶段61项测试通过；本次分时接入新增15项测试，连同日线计数、历史核对、图表加载与绘制测试共96项通过。覆盖1–9、双方向、相等/反转、缺口、去重、午休、跨日、当前分钟确认与降级来源；图表测试在渲染调用瞬间复制标记，防止绘制后才追加数据而误报通过。
