# 作者文稿关系图：第一段接入与边界（2026-09-23）

本次只接入“原文准入 → 作者观点候选 → 原文回查”。参考包 `Fioona_Graph_Integration_20260923.zip` 是离线评审资料，不是生产数据迁移脚本；没有把包内候选关系直接写入用户数据库。

## 行为与取舍

- 视频需有正文、ASR 状态为 `complete` 且未被质量标记为待复核；疑似转写提示词隔离。图文需已取得 OCR 文本并完成校对；缺少 OCR 与 OCR 待校对分别显示。通过这些检查仅允许提取“作者观点候选”，不代表转写已人工听校、公司身份已核验或存在真实供货关系。
- 新记录标注 `creator-industry-graph/v2`，保存原文 SHA-256、引用原文和字符偏移。旧记录留在同一个作者文件中，但不计入新流程的已分析数量；只有新版候选进入当前图。
- 作者关系图按主题组织真实提取的有向实体关系，可拖动、缩放并点选回查。图表最多渲染当前筛选下前 60 条以限制页面成本；关系列表保留全部已载入关系。主题到实体的虚线仅表示视图分组，不表示商业供货。
- `GET /api/industry-chain/creators/:id` 增加 `reviewQueue`、`blockedCount`、`legacyCount`。`GET /api/industry-chain/creators/:id/observations/:observationId` 只读返回该作者的一篇原文、正文哈希、转写分段和状态，并设置 `Cache-Control: no-store`。现有 LAN 只读范围限制仍适用。

## 仍未解决

- 本轮后续增量已增加本机逐篇校对通道：图文逐张原图与 OCR 对照，视频归档媒体与 ASR 对照；保存原文哈希、媒体身份、人工修正与时间。同媒体重识别保留修正，媒体变化重新待复核。后台分析尝试与一小时退避写入单独的原子 JSON，重启后不会立即重复调用模型。详见 `Fioona_AI_Handoff_20260923.md`。
- 图中的实体不自动绑定证券代码。公司的具体业务、概念、市值、涨跌幅、产业地位和第一／第二梯队仍需独立、可追溯的数据源与核验规则；本次不推断这些事实。
- 本次未导入 157 篇作品、未批量调用 AI、未修改真实用户资料库，也未升级当前运行的桌面程序。单元／接口测试和隔离浏览器空资料库冒烟测试不能替代真实 Fioona 文稿视觉验收。
