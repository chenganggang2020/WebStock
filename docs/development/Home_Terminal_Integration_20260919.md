# 首页紧凑终端接入

## 范围与决定

按原始 Compact V2 的 `dashboard()` 组成接入现有程序：左自选、上指标、中主图、右盘口、下榜单。不引入原型合成数据、不修改后端协议、不写持仓或同花顺文件。保留现有未提交修改，不在本任务提交 Git。

图表与个股详情共用同一组 DOM、状态与请求取消逻辑，在首页与详情页之间移动节点，不复制图表实例或新建另一套行情轮询。扩展首页刷新可见性条件。旧的指数比较、量能大图、ETF与期货保留在可展开的“市场全景”中。

## 分步验收

1. 组合与联动：共享图表容器进入首页；左侧分组区分本地/同花顺只读；选择股票不离开首页；快速切股不串数据。单元测试与真实浏览器验证。
2. 指标与榜单：复用现有指数分时、情绪、量能、板块、风险数据；空值不变为零；保留来源及时间。验证深浅主题、1280和1920宽度、日线切换及详情往返。
3. 回归与交付：全量Node测试、浏览器运行截图；独立记录使用的数据目录、运行入口、生产/测试数据区别。只有实际画面通过才打包；不以健康接口代替布局验收。

## 实施结果

- 左侧为真实本地/同花顺只读分组；选择股票保持在首页，主图、盘口与股票信息同步。
- 顶部复用真实指数报价与分时、情绪样本、沪深量能，修正 `index:sse` 与 `sse` 标识不一致导致小图空白的问题。
- 中间与详情页共用原分时/K线实例，支持分时、日/周/月线与原有指标；右侧五档补充档位、股票代码、报价日期/时间和数量单位。
- 下方为行业主力净额排行、概念涨幅排行及已有风险观察，不把普通主力净额称为暗盘，也不将行业与概念相加。
- 选股立即清理前一只股票的图表/盘口，沿用异步请求序号与证券校验；分钟对齐价明确标注，不把重建分钟价当五档委托来源。
- 现有完整市场全景与个股研究资料保留在折叠区；首页展开个股研究时才启用该页明暗盘读取。
- 既有分批快照轮询覆盖首页当前分组；未创建第二套无界轮询。页面数据不变时不替换列表 DOM。
- 更新静态缓存版本至 v31。无新增依赖、数据库表或后端协议；未复制原型的合成行情。
