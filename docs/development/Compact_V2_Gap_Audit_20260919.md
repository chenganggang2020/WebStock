# Compact V2 对照审计与本轮修复

## 范围与顺序

1. 对照原始 26 页包（PAGES、三份接入规范、原型 app.js）和当前源码、实际运行接口。区分布局落地、业务数据接入、原型演示、未验收，不将页面能打开等同完整交付。
2. 修复证据库标题与作者隔离：保留存储的原始标题；有效标题直接展示，平台占位标题使用有标记的内容摘录；按精确作者筛选，作者列表不受 500 条内容列表上限影响；切换期间清空旧作者资料并拦截迟到响应。先失败测试，再实现及真实数据只读验收。
3. 将深色主题改为中性炭黑及灰色层级，保持浅色、紧凑尺寸、行情语义与原有业务接口。面板和图表同时调整，检查主次文字对比度及实际截图。
4. 全量回归后固定源码再打包，不在构建期间继续修改打包文件。旧实例不强退；未切换时明确标注只有预览生效。

## 已核实的主要差距

- `industryResearchGraph.buildGraph` 是主题—环节—产品分类树，最多 16 条；不是原包上中下游三列产品关系图。`renderResearchDetail` 每次选择节点会 dispose/init 图表，也未达到原包“选择只更新证据栏”的要求。
- 2026-09-19 本机 GET `/api/industry-chain/research/topics` 返回 4 个主题，全部 sourceUrls 为空、currentVersionId 为空、enabled=false。没有真实证据图谱可供显示。不能把原型里的合成节点移入正式数据补齐。
- 当前证据库只按发布时间混合作者，直接展示来源占位标题，造成用户截图的问题；本轮修复，不改写历史事实。

## 配色选择

设计参考技能比较了 Geist 中性色、Radix Gray Dark、Carbon Gray 100。采用 Radix 风格的无色相灰阶：背景 #111111、面板 #191919、次级面板 #222222、边框 #3e3e3e、主文字 #eeeeee、次文字 #b4b4b4。蓝色仅用于焦点/链接；涨红跌绿保持金融语义。没有照搬品牌、字体授权资产、宽松营销页布局。

## 新增只读接口与审查边界

- `GET /api/knowledge/authors`：返回 `{author,count,latestPublishedAt}` 数组，按现有来源的作者文本聚合；不受内容列表500条上限影响。它是已保存资料目录，不是平台全部作者/作品目录。
- `GET /api/knowledge/sources?authorExact=...`：精确匹配保存的作者文本；空字符串只匹配未注明作者。旧 `author` 模糊参数保持兼容；界面不再请求混合作者列表。返回增加最多240字符 `contentPreview`，不返回全部正文。
- 目前作者身份仍沿用原库的作者名称；将来支持重名作者跨平台时需单独迁移到稳定来源ID，本轮不把名字匹配说成平台身份认证。
- 质量审查覆盖：参数化查询、HTML转义、原文/摘录区别、空目录/空选择、迟到响应、编辑后作者定位、有限列表长度、旧业务协议兼容。未引入新依赖和数据库迁移；未运行真实保存/删除/账户操作作为验收。
