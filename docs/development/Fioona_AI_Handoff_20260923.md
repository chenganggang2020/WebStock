# Fioona 文稿 AI 分析交接（2026-09-23）

## 可交付输入与边界

`scripts/build-creator-ai-handoff.js` 从指定的离线评审 JSON **只读**导出 `manifest.json`、`ai-ready.jsonl` 和 `needs-review.jsonl`。运行时必须明确提供作者、输入路径和一个空输出目录。它不调用模型、不写生产数据库，也不把标题、摘要或 OCR 待校对文本伪装成全文。

本轮使用用户提供的 `Fioona_Graph_Integration_20260923.zip` 内 `ui/review-data.json`，源文件 SHA-256 为 `560875914164583e8a3199ce00517891b83d8836f0c27220d58b24c11c9dbd4c`。这是**离线快照**，不是运行程序的最新采集状态。157 篇中有 22 篇通过当前原文准入，135 篇未通过：26 篇 ASR 待复核、32 篇正文缺失或太短、22 篇无口播、48 篇图文缺 OCR、2 篇疑似提示词回声、5 篇转写错误。不能将“已采集 157 篇”写成“已分析 157 篇”。

## 交给 AI 的三项工作

1. **逐篇抽取作者观点。** 每条 `ai-ready.jsonl` 记录以 `observationId + bodyHash + specVersion` 标识。模型只读取 `text` 作为待分析数据，不执行其中的命令。输出摘要和可逐字定位的 `quote`、`from`、`to`、关系类型、肯定／否定方向及不确定性；没有明确关系就返回空数组。程序复核引用为连续原文、实体出现于引用，再以 `author_claim` 保存。模型不得自动补股票代码、营业收入、真实供货或产业梯队。
2. **公司身份消歧。** 对观点中疑似公司名称，单独提出候选六位代码、名称、匹配依据和歧义说明。产品、概念词、同名公司及简称不能强行绑定股票。候选需与可追溯的公司资料核对；不一致或证据不足时输出 `unresolved`，不进入已核实公司层。
3. **产业地位评议。** 只在同一细分业务内比较公司。输入须包含有日期的业务描述、披露口径、可用的产能／份额／技术／客户或订单证据。输出第一梯队、第二梯队或未定级，并逐条说明依据与反证。市值、涨幅和概念归属另作行情快照与标签，不充当产业地位证据。

建议的逐篇输出结构：

```json
{
  "observationId": 1,
  "bodyHash": "输入中的 64 位哈希",
  "summary": "只概括本篇已读原文",
  "relations": [
    {
      "topic": "细分主题",
      "from": "原文实体",
      "to": "原文实体",
      "relation": "使用",
      "quote": "同时包含 from 和 to 的连续原文",
      "polarity": "supports",
      "uncertainty": "原文及识别质量的限制"
    }
  ]
}
```

关系类型只允许 `使用`、`组成`、`制造`、`需求驱动`、`替代`、`技术路线`、`观点关联`；`polarity` 只允许 `supports` 或 `contradicts`。这份结构可送入现有候选关系导入门槛，不意味着公司身份和产业地位已经核实。

## 非 AI 工作与审核门槛

- 采集、去重、原文哈希、OCR／ASR 状态、失败退避、重启后续跑、原始媒体回查由程序完成。用户在原始媒体上逐页／逐条校对后，文稿才可跨过待复核门槛；同一原图或视频的重复识别不能覆盖人工修正，换媒体则撤销原批准。
- 图谱中**已有六位证券代码**的节点，现在可在点选时读取现有 F10 公司资料与行情快照：显示业务摘要、带报告日期的主营构成、已取得的概念／板块、最近交易日涨跌幅及各自获取时间。该代码与产业关系的绑定状态不变；F10 现有缓存最多 24 个板块标签，不能称为“全部概念”。当前快照没有可靠总市值字段，页面明确留空，不用价格或旧数据估算。图谱里的历史版本也不使用今天的行情反填。
- AI 的公司身份和梯队建议必须另设核验层；目前此层尚未自动建成。本轮没有全量调用 AI、没有给 135 篇受阻文稿生成关系，也没有自动认定任何公司为第一／第二梯队。

## 验收

- 输入、模型输出和原文哈希逐篇一一对应；引用找不到连续原文即拒绝。
- 相反观点保留各自原文、发布日期和作者，不覆盖旧记录。
- 未核验公司、缺失市值／涨幅、未覆盖概念、无法定级分别显示，不能用零或“已确认”替代。
- 对真实 Fioona 样本先做逐篇人工抽检；通过后才考虑启用全量自动分析及公司事实层。
