# Fioona 图谱接入进度（2026-09-23）

本文件记录本机实际接入，不冒充原 ChatGPT 对话中的 `Fioona_Graph_Integration_20260923.zip`。原包在该对话里只有 `sandbox:/mnt/data` 链接，当前 Codex 工作区未取得包体。接入依据为该对话可读取的交付说明、[需求规格](Creator_Industry_Graph_V2_20260922.md)和现有源码；收到原包后仍需逐文件对照。

## 已落地、已验证

- 作者关系图由真实作者观点边绘制局部可拖动、可缩放图；点击边查看原文证据，输入实体可切换焦点。当前焦点和全部筛选关系的数量分别标明，完整关系仍在列表中。
- 新增“文稿质检”只读视图，逐作品区分缺正文、图文 OCR 待识别、ASR 待复核、疑似提示词污染、待分析、旧规则待重审、已分析有关系、已分析无关系；点击作品查看正文、ASR 模型、质量提示及时间片段。图文标题或配文不冒充完整图片文字。
- 自动关系提取跳过待复核 ASR 和已知提示词回声。新版关系导入同样拒绝这些文稿；旧关系继续保留，但显示为旧规则待重审。
- 新提取规则不再每段固定最多 4 条；同一文稿、同一规则版本保持幂等，升级规则会重新分析而不覆盖旧记录。旧 `webstock.creator-industry-review/v1` 导入标记为 `legacy-review/v1`，不能冒充 V2 完成。
- 使用隔离测试数据执行 31 项针对性测试通过；Edge 隔离页面检查了图谱定位、文稿质检、原文展开。预览数据是合成夹具，不是 157 条作品的生产验收。

## 接口变化

- `GET /api/industry-chain/creators/:id` 增加 `blockedCount` 和 `reviewQueue`。`reviewQueue` 仅返回作品状态与摘要元数据，不在列表返回全文。
- `GET /api/industry-chain/creators/:id/observations/:observationId` 只读返回单条正文与 ASR 片段。
- `POST /api/industry-chain/creators/:id/import` 接受 `schema`。仅 `webstock.creator-industry-review/v2` 标为当前规则；缺省和旧 v1 保持 legacy 状态。写入仍受原有本机访问限制、原文引文和端点校验。

## 关键取舍

旧的四条上限和只按正文哈希跳过会让“已分析”掩盖覆盖不足。此次保留旧证据并增加规则版本，不删除历史。自动图谱准入选择保守：`needs_review`、无明确完成状态及已知提示词回声不自动转为关系候选；误拦截可以在原文质检页发现，后续需有版本绑定的人工接受机制再放行。
