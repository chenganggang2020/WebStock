## 已确认的问题与改动

| 问题 | 本轮处理 |
| --- | --- |
| 报价批量请求超时，错误后缀包含长 URL、证券代码 | 每批最多 50 个唯一代码；失败批保留旧报价，其他批继续；短提示区分超时、部分不可用 |
| 成功请求后仍残留旧失败提示 | 当前刷新完成后更新快照状态；较旧请求不得覆盖新请求的最终提示 |
| 连续滚动重复进入加载更多 | 增加单次加载保护；先显示证券目录，报价成功后按行更新，不在请求尾部重绘旧搜索列表 |
| 行情抽屉约 380px，涨幅被省略 | 桌面增至 600px，明确价格、涨幅、小图列宽；窄屏允许表格横向滚动 |
| 视频状态刷新替换整个阅读区 | 按作者和资料 ID 建立稳定壳；仅媒体路径变化时替换播放器，普通状态和标签切换不搬动视频节点 |
| 状态刷新重建数百条封面卡片 | 首屏 40 条，按需每次增加 40 条；相同内容保留列表 DOM；搜索防抖 180ms |
| 内容窄列居中，视频、逐字稿、规则、评论挤在一起 | 左侧视频与操作，右侧阅读；逐字稿、观点线索、评论、来源分开；小屏改为上下布局 |
| 页面隐藏后仍刷新显示状态 | 隐藏窗口或非采集页不轮询这部分 UI；桌面后台采集任务不受影响 |

“行情刷新失败”代表本轮报价请求失败，不代表证券目录或历史数据删除。
周末最近收盘快照本身不是失败；旧快照、缺失数据不标为交易所实时值。

## 审查与边界

- 正确性：失败批不清零旧数据，异步作者/日期防串资料逻辑保留。
- 可维护性：沿用现有模块与样式，无新运行依赖、数据表或后台协议。
- 安全：展示文本继续 HTML 转义；未操作持仓、同花顺、外部登录或真实交易。
- 性能：降低实际 DOM 节点量和重复替换；尚未进行长时间 ASR 与视频播放并行的压力验收。
- 数据质量：旧 ASR 内容可能有错字，本轮没有重转写或把规则摘句改称 AI 结论。
- 采集日志中的作者身份不匹配仍维持阻断，本轮没有绕过保护去补采。
