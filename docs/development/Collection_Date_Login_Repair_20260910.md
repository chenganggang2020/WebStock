# 采集日期联动与登录墙误判修复

## 原因与现场证据

2026-09-10 晚间核查运行中的旧版（本地端口 3000）：

- 运行日志每轮读取主页 20 张卡片，详情和转写为 0，却显示已完成；视频区域是全部 367 条抖音历史作品，而不是当天任务的视频。
- 已保存视频的最新发布日期为 2026-09-03 15:34 北京时间。这条视频首次采集为 2026-09-10 00:07，两者不可互换。
- 在实际程序中打开“登录 / 检查账号”，模型先生主页显示“登录后免费畅享高清视频”登录弹层，背景提示“看更多 最新作品 登录”。未替用户扫码、输入验证码或清理 Cookie。
- `inferVisibleLoggedIn` 原先将“通知 消息 投稿”导航优先判为已登录；未登录页也保留这些导航及部分旧视频。明确登录墙文案现在优先拒绝。

## 本轮变更

1. 当天发布：按实际 `publishedAt` 的北京时间日期筛选视频；缺失时间不拿 `firstSeenAt` 代替。
2. 当天任务处理：按运行开始日期筛选日志，并用该运行的 `items.contentId` 映射视频。单次运行按钮精确选中本轮；零项目保持空列表。
3. 全部本地历史：显式查看历史资料。当前观察记录最多载入 500 条，运行列表最多 100 次；旧运行的项目可能超出本地列表载入范围，不宣称全量。
4. 日期 API 先按作者与北京时间筛选再限制条数；非法日期返回 400；状态与运行接口不缓存。
5. 保留最新 6 次运行用于当前阶段状态，不让历史日期选择覆盖当前转写状态。拦截作者、日期的迟到响应；切作者先清空旧内容。相同轮询响应不重建视频区域，运行展开状态按 ID 保留。
6. 中文、斜线、点分隔的绝对发布时间统一按北京时间解释；非法新时间保留旧有效值。未猜测“今天/小时前”等相对时间。
7. 滚动中登录失效标记 `login_lost`，保持扫描不完整。自动队列中有合法发布日期的最新发现优先于更旧的新发现，仍保留身份核验、重试退避和上限。
