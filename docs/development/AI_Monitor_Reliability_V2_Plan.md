# 智能量化前向模拟可靠性修复（2026-09-07）

## 范围与边界

用户授权继续实现智能量化模拟并修复审查发现的问题。沿用独立 10 万元账户、既有 OpenAI/外部模型交接、Windows SQLite；不下实盘委托、不复制真实资产进模拟账本。此次交付是可审计的前向模拟，不把夹带未来信息的历史提问称作回测。保留所有既有用户修改，不提交整个脏工作区。

## 顺序与验收

1. 决策时序与交接（纸面服务、契约、SQLite、测试）
   - 准备截止时间与模型收到时间分离；10:33 收到的建议不能在 10:31 成交。
   - 手动交接采用服务端保存的原始上下文；过期、未来、重复回填不能新增订单。
   - 每个交易时段幂等，公开行情/持仓不足时明确阻塞。
2. 自动盯市与绩效（纸面服务、模型服务、测试）
   - 无待成交订单时仍更新已有持仓净值；不产生初始化买入。
   - 拒绝倒序/未来/过期价格，缺失保留真实缺失状态；显示净值覆盖和费用。
3. 调度恢复（调度器、交易日历、运行日志、测试）
   - 按已验证的交易日历跳过休市；未知年份失败关闭。
   - 失败有限重试；过期时段只记漏跑，不倒填历史建议。
4. 数据完整性（板块、健康状态、测试）
   - 兼容上游实际缩小分页；去重和安全上限保留。
   - 区分缓存存在和行情新鲜；同花顺状态使用实际 OCR/导出通路。
5. 手机与预警（访问中间件、移动快照/推送、测试）
   - 仅可信本机 HTTPS 代理获得正确的同源判断；不信任远程伪造转发头。
   - 配对手机只读业务数据，仅允许必要的通知订阅操作。
   - 移动端可查看模拟状态；通知区分持仓变化和实际预警事件。
6. 交付验证
   - 每块先补失败测试，再实现；最后运行全量 Node 回归和隔离 API/页面验收。
   - 源码、打包产物和生产数据验证分开报告。模型实际回复、同花顺登录、Tailscale 授权与 iPhone 真机不以测试替代。

## 保留的外部条件

- 同花顺交易窗口必须处于可读取状态；不访问密码、绕过登录或注入交易软件。
- 模型直连需要有效 API 配置；既有外部模型任务可通过同一准备/回填契约运行。
- 不自动发布公网服务；手机 Tailscale 登录授权由用户完成。
- 全市场历史基线与长期跨交易日验证单独报告，不把空账户或短期样本解释成策略有效。

## 验证记录

### 已实现的契约

- 服务端保存准备 UUID、原始提示词/股票池/上下文及失效时间。回填只接受原始准备；实际收到回复时才设置 `advisedAt`，`marketAsOf` 保留准备时间。公开路由不允许客户端覆盖运行时钟或调度时段。
- 股票报价、持仓、量能原生时间和指数抓取时间检查不晚于截止且在 5 分钟内；无逐证券交易时间的指数仅标注抓取时间，不能作为成交依据。已存研究只在其观察、生成和入库时间均不晚于截止时纳入，外部文本作为证据而非指令。
- 未收到模型或建议无效时无成交。新 hold 撤销该股待执行意图；过期建议取消；迟到旧行情不能倒填最新净值之前。同批模拟按选定行情时间顺序计算现金，不使用未来的现金和仓位。
- 每股保留价格观察时间，拒绝逐股倒序。成交及盯市快照明确全仓覆盖、缺价警告；部分缺价净值不进入“已观察最大回撤”的有效点集。界面收益包含费用，不把空账户称为已有表现。
- 自动运行按三个时段，窗口 5 分钟，最多 3 次尝试、递增退避，状态持久化，漏跑不补问历史模型。仅验证 2026 日历；未知年份暂停自动判断。
- 新增运行日志随 JSON 备份恢复；模型准备记录是短期能力凭证，**不恢复**，导入后需要重新准备。原始决策上下文仍随账本备份。常规列表分页不再截断决策/订单/成交的导出查询；备份自身仍有安全数量上限。
- 模拟面板置于 AI研究顶部，显示权益、现金、盈亏、收益率、费用、可验证净值时间、运行记录、最近 20 条建议/订单和原始回复。手机独立只读展示模拟账户概览，不泄露原始模型上下文。
- 配对手机仅可访问明确的只读移动 API，以及通知订阅/取消/测试；无法调用桌面账户写操作、备份或 AI 设置。可信本机 Tailscale HTTPS 代理能通过合法同源检查；远端伪造转发头无效。未主动开放公网或登录 Tailscale。
- 通知检查默认 60 秒，无订阅时不抓取；除数量/明显资产变化外，还比较持股代码与数量指纹。已配置的自选上下预警价只用盘中新鲜行情判穿越，持续越界不重复；短时缺价保留触发状态。锁屏通知不包含代码、持仓和金额。自动推导支撑阻力未自动等同于用户预警阈值。

### 规则来源与限制

- 2026 休市区间依据 [上交所休市安排](https://www.sse.com.cn/disclosure/dealinstruc/closed/) 核验，包括调休周末不开市。
- 科创板最小申报数量依据 [上交所科创板问答](https://edu.sse.com.cn/tib/qa/)；特殊股票规则不完整时拒绝成交，避免沿用过时 ST 涨跌幅假设。[2026 交易规则通知](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml) 提示规则存在生效日差异，因此没有将一个固定 ST 比例用于所有证券。
- 回撤图基于最近最多 5000 个已保存净值点；不是逐笔连续风险，也不保证覆盖历史峰值。暂无模型收益相对基准、除权除息/分红/停复牌全生命周期、盘口排队、成交参与率或真实冲击成本建模。
- 模型通道为现有 OpenAI 直连或结构化交接；不是登录并持续控制某个 ChatGPT 网页对话。没有 API Key 时可沿用已配置外部模型任务，但不能把任务启用视作模型已经回传。

## 使用新版

1. 退出当前旧 WebStock，再打开 `dist/portable/WebStock-Simulation-20260907.exe`。新版与旧版在同一便携目录，会沿用现有 `WebStockData`；不要把 EXE 单独挪走后误以为空白数据是丢失。
2. 进入“AI研究”顶部“智能量化前向模拟”，核对独立 10 万元账户。真实同花顺持仓只作风险上下文，不进入模拟本金或真实委托。
3. 在 Windows 登录同花顺并保持“资金股票”页可读取；接通有效模型直连，或沿用已配置外部模型任务的准备/回填交接。实际行情及持仓检查通过后，自动时段才可形成建议和等待模拟成交。
4. 观察运行记录、阻塞原因、建议、订单、费用及有时间依据的净值。建议晚到、行情过期、休市或数据不全时不能据此虚构补单。
5. iPhone 只读页面与访问控制已修复，但仍需完成个人 Tailscale 登录/配对并做真机验证；此次没有开放公网或替用户完成登录。
