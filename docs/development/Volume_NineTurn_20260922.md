日期：2026-09-22，北京时间。仅本轮截图涉及的量能、情绪文字和九转历史核对；未展开产业图谱、自动交易或全市场历史建库。

## 真实原因与改动

1. 旧运行程序的量能源是 `sina-public-index-5m-volume`，不是一分钟成交额。2026-09-21 对比 09-18 仅48个五分钟点，但视图强制242格一分钟轴，所以09:49等悬停点为空。15秒刷新不能提升上游数据粒度。
2. 新备用链：东方财富一分钟成交额 → 腾讯一分钟累计成交额相邻差分 → 新浪五分钟成交量。只有两个指数、两个共同日期可对齐才接纳来源；不混合来源或把成交量称作金额。
3. 腾讯日内历史公开接口本轮实取：两个指数各5日、每天242条。相邻快照才计算分钟差额；缺口不被分摊或补零，负差不变成零，午休不制造90分钟数据。它是公开指数代理，未证明等于全A全市场官方统计，也不承诺交易所实时。
4. 五分钟降级用48格横轴，午后首格13:05；一分钟用242格，午后13:00。午休视觉连接保持，短时窗口仍按早午场重新预热。累计统计要求完整对齐槽，不能把99%覆盖称为完整。
5. 情绪评分卡解除正方形高度约束，文字保持卡内；量能金额单列显示并写明“元”。情绪764只抽样的口径没有改成全市场。
6. 九转原来已有“收盘相对4根前、连续9次”的简化计数，但只画最新状态。现在逐日计算，首次计到9才在原日画标，连续10/11不反复发新事件；涨/跌方向分别计数，平价重置，空记录保留位置并打断，未收盘只暂记，不确认为事件。
7. 日线“形态提示 → 简化九转·历史核对”可展开每次事件后第1/5/20根日线的收盘涨跌；尚未满窗口显示待满，显式缺口显示缺口。图标提示也显示该事件的事后核对，绝不把后续价格放进触发规则。
