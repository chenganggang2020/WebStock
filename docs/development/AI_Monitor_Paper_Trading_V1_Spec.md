# ChatGPT 盯盘模型模拟交易 V1 规格

> 2026-09-07 修订：时序、交易日、持仓采集与移动权限以 [V2 可靠性说明](AI_Monitor_Reliability_V2_Plan.md) 为准。此功能是前向模拟，尚不构成经过验证的历史回测或盈利策略。

## 目标

在现有“AI 研究 → 证据决策与纸面组合”中增加可持续跟踪的 ChatGPT 盯盘模拟交易：

- 默认初始资金 100,000 元，只记录虚拟买卖，不连接券商。
- 用户可选“今日开始”或“下一交易日开始”。今日开始仅从启用后的下一个可用行情点起算，不回填早于启用时间的成交。
- ChatGPT 根据当时可见的行情、持仓、现金、市场情绪、量能和已有研究证据输出 `buy` / `sell` / `hold` 建议。
- 每次建议保存输入截止时间、数据来源、提示词摘要、模型、原始回复、结构化决策和校验状态。
- 模拟账户展示现金、持仓、总权益、当日/累计盈亏、最大回撤、待成交/拒绝订单及完整模型对话记录。

V1 将“从今天/明天开始看表现”称为**前向模拟**。“回放已保存的历史建议”才称为**建议回测**。不允许在已知未来行情后补问 ChatGPT 并把结果当成历史建议。

## V1 产品决策（已确认）

1. **账户**：复用现有 `paper_portfolios` 纸面组合，新增决策、订单和成交账本，不再建第二套模拟账户。
2. **股票池**：默认只评估当前纸面组合候选、纸面账户已有持仓和每次判断前最新同步的同花顺真实持仓；不合并全部自选股，也不让大模型无边界扫描全市场。
3. **模型通道**：同时支持已配置 OpenAI API 的直接调用和无 Key 时的 ChatGPT 提示词复制/结果粘贴。不自动操作 ChatGPT 网页、登录或验证码。
4. **盯盘频率**：建立前向模拟后默认启用每交易日 09:35、10:30、14:50 三次自动判断，并保留“立即判断”；API 次数不作为默认限制，但同一组合、同一时段必须幂等，不能重复调用。
5. **执行价**：模型实际回复后下一根可验证 1 分钟行情；准备和订单各自最多有效 5 分钟，旧订单不跨日、不倒填早于已记录净值的成交。同批次按实际选定行情时点排序。
6. **A 股规则**：只做多，普通股票买入 100 股整手、科创板最低 200 股且以上按 1 股递增；T+1、现金保留、持股数与单股上限。涨停不买、跌停不卖，零量/缺量/缺价不成交。ST、新股标记及未验证板块暂时拒绝，不能猜测适用规则。
7. **成本默认值**：买卖佣金 2.5bp、每笔最低 5 元；卖出印花税 5bp；单边滑点 2bp。这些是模拟假设，不是用户券商费率；输入上下文保存规则，成交逐笔保存原始价、执行价、佣金和税。
8. **模型建议不直接等于下单**：结构化校验失败、数据过期、缺少截止时间、代码不在股票池或超过仓位上限时，订单必须被拒绝并显示理由。
9. **同花顺持仓先同步**：每次模型判断前先只读同步同花顺当前持仓，并保存来源与文件/快照时间。同步失败或来源不是本交易日时，本轮自动判断和新订单均被阻塞，不能静默沿用旧持仓。
10. **同步边界**：支持已有窗口 OCR 只读采集、明文持仓导出及显式复制快照。判断时要求最近 5 分钟的本交易日完整持仓。窗口须已登录且可读；无法读取时阻塞，不读取密码、注入客户端或发真实委托。

## 模型输出契约

OpenAI API 直调使用 JSON Schema 约束的结构化输出；手动 ChatGPT 回填使用同一契约本地校验。核心字段：

```json
{
  "asOf": "2026-09-02T06:50:00.000Z",
  "marketView": "neutral",
  "cashTargetPercent": 30,
  "orders": [
    {
      "code": "603618",
      "action": "hold",
      "targetPositionPercent": 10,
      "confidence": 62,
      "reason": "限价与量能风险尚未解除",
      "invalidation": "放量打开涨停且跌破盘中支撑"
    }
  ],
  "portfolioRisk": ["单股涨停后流动性不足"],
  "nextReviewAt": "2026-09-02T07:00:00.000Z"
}
```

`additionalProperties` 必须禁用；所有订单字段必须存在。结构不合法时保存原回复与失败原因，但不生成模拟订单。

## 数据与存储

复用：

- `paper_portfolios`：账户、初始本金、状态和风险约束。
- `paper_portfolio_items`：允许模型评估的候选。
- `paper_portfolio_positions`：当前模拟持仓。
- `paper_portfolio_snapshots`：现金、市值、权益、盈亏与净值序列。

新增：

- `paper_model_decisions`：模型、提示词摘要、点时行情摘要及哈希、原始回复、结构化结果、校验状态。
- `paper_orders`：买/卖/保持、目标仓位、建议时间、待执行/成交/拒绝/取消状态及原因。
- `paper_fills`：成交时间、行情来源、原始价、滑点后价格、数量、佣金、印花税和现金变动。

数据库依然是 Windows 主机唯一事实源；备份导出/导入必须覆盖新表。

## 代码风格

继续使用现有 CommonJS、Express、SQLite 和原生 JavaScript，不引入新回测框架。订单约束用小型纯函数表达：

```js
function validateOrder(order, account, market) {
  if (!/^\d{6}$/.test(order.code)) return { accepted: false, reason: '股票代码无效' };
  if (!account.allowedCodes.has(order.code)) return { accepted: false, reason: '不在已审核股票池' };
  if (!market || market.stale) return { accepted: false, reason: '行情不可用或过期' };
  return { accepted: true };
}
```

## 运行前置

- 自动 OpenAI 判断需要在运行环境设置有效的 `OPENAI_API_KEY`；只有 ChatGPT 网页订阅而没有 API Key 时，程序保留提示词复制/JSON 回填流程，不伪装成自动 API 已可用。
- 同花顺自动同步需要当天更新的明文持仓导出。可用 `WEBSTOCK_THS_HOLDINGS_FILE` 指定单一文件，或用 `WEBSTOCK_THS_HOLDINGS_DIR` 指定导出目录；没有明文导出时，使用页面的“同步同花顺持仓”复制/粘贴入口。
- 同花顺同步数据只进入模型风险上下文；真实账户和 10 万元纸面账户始终分账，模型与调度器都不连接券商委托。

## 测试策略

1. **纯逻辑**：JSON 校验、目标仓位转整手数量、佣金/印花税/滑点、T+1、超卖、涨跌停和现金约束。
2. **服务测试**：建立 10 万元模拟、买入、隔日卖出、记录费用和已实现盈亏，不允许同日回转。
3. **API 测试**：有 Key 路径使用本地假模型响应；无 Key 返回可复制提示词；粘贴非法 JSON 时不产生订单。
4. **页面测试**：建立 10 万账户、选开始时间、触发一次模型判断、看到建议与订单状态。
5. **全量回归**：不改变现有量化策略回测、交易记录和纸面组合逻辑。

## 边界

### 始终执行

- 保存点时数据截止时间、数据源、原始模型回复和处理结果。
- 订单在模型建议后的行情才能成交，不用当根已知价反向填充。
- 所有不可成交状态显示明确原因，不静默忽略。
- 继续支持无 API Key 的 ChatGPT 手动交接流程。
- 模型输入明确区分“同花顺真实持仓（只读参考）”与“纸面账户持仓（模拟成交结果）”。
- 页面显示同花顺同步方式、来源时间和是否满足本轮判断的新鲜度要求。

### 永不执行

- 连接券商、生成可提交委托、自动实盘交易或修改现有真实交易记录。
- 在已知未来价格后重新询问模型并把结果冒充成历史信号。
- 对缺失行情补价、补量，或将模拟收益表述为可实现收益。
- 把 ChatGPT Plus/Pro 订阅当成 OpenAI API 额度。

## 成功标准

1. 用户可以 100,000 元建立一个“今日”或“下一交易日”开始的前向模拟。
2. 每次 ChatGPT 决策都能回查原始回复、市场截止时间和数据源。
3. 合法建议只在下一个可用行情点模拟成交；无效/过期/超约束建议被拒绝。
4. 页面清楚展示现金、持仓、成交、费用、权益曲线、累计收益和最大回撤。
5. 无 Key 时可复制 ChatGPT 提示词并粘贴结果；有 Key 时使用结构化输出契约。
6. 针对测试、全量测试和真实页面流程通过，且不产生真实交易副作用。

## 已关闭问题

1. 自动模型判断默认开启，每交易日 09:35、10:30、14:50 三次；API 次数不作为限制。
2. 股票池使用“纸面组合候选 + 纸面持仓 + 最新同花顺真实持仓”，不合并全部自选股。
