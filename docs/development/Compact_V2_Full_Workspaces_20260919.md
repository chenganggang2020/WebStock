本轮目标：按用户提供的原 ZIP 及随后确认的固定视口要求接入现有 UI，而非另造演示站。保留现有真实数据、来源/缺失标识、控件 ID、账户身份和业务服务；不引入原型合成行情，不改采集队列、生产数据库或同花顺文件。

## 实施顺序与验收

1. 公共固定视口、原包配色和导航。已有 26 入口保留；展开子页改为独立可见内容，不用滚动定位。验收：切页、前进后退、直接地址进入保持正确页面。
2. 首页分组下拉、股票列表内部滚动、指标/主图/盘口。榜单、市场全景、研究分别打开。验收：股票联动、图表实例复用、源状态不丢、正文不裁切。
3. 资金、竞价、ETF、证据、作者、健康子页拆分现有 DOM。验收：唯一 ID、事件不丢、隐藏区不挡当前页、控件可达。

5. 实际前端连接运行程序的本机数据进行只读展示（写入禁止的验收入口），保留截图。回归、构建在确认布局后进行，既有程序不强退。指定 EXE 未切换前，不称旧运行窗口已经更新。

## 本轮结构与接入决策

用 `fixedWorkspace.js` 组合既有 DOM，不复制表单、图表或账号状态。26 个界面入口仍复用 18 个现有业务视图；子页拥有独立面板与地址，不再用滚动跳转假装换页。新增 `fixed-workspace.css` 冻结原包颜色、密度与固定视口；股票、评论等原业务事件保留在原节点上。评论页保留其原有 tab 状态机，不能叠加另一个独立 tab 状态。

| 页面组 | 实施内容 |
|---|---|
| 首页、个股、板块、竞价、ETF | 首页分组下拉；股票独立滚动；真实共享图表和盘口；榜单/全景/个股研究独立分区；竞价两栏且保留缺失状态 |
| 自选、持仓、最近查看 | 保留真实分组身份与操作，表格区域独立滚动，不再整页滚动 |
| 资金、明暗盘、轮动、回放 | 四个独立入口；金额表格紧凑化；旧数据日期、窗口覆盖和估算口径保留 |
| 产业链、候选、资讯、AI、证据、评论、研究记录 | 目录/主区域分离，产业链图表与证据独立阅读，资讯列表+正文摘要，研究功能分区，评论保留原四项工作区 |
| 采集、作者 | 左任务/作者；中视频列表；右视频、逐字稿、评论/来源；队列、运行记录、分析材料独立切换 |
| 模拟、交易、统计、设置、健康 | 保留真实计算和控件，内容区滚动；设置目录化、健康入口直达，浏览器不冒充桌面能力 |
