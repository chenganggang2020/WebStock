# ChatGPT 盯盘模型模拟交易 V1 实施计划

## 概览

在现有纸面组合上增加可审计的前向模拟交易闭环。真实同花顺持仓只作为模型上下文和股票池来源；纸面账户仍以 100,000 元独立计算。所有模型决策、拒绝原因、待成交订单、成交费用和净值变化写入本地 SQLite，不连接券商。

## 架构决定

- 复用 `paper_portfolios`、候选、持仓和净值表，新增监控设置、模型决策、订单与成交表。
- 每次判断先同步同花顺持仓；无本交易日可验证来源则失败关闭，不用旧数据继续生成订单。
- 自动时点为 09:35、10:30、14:50；用“组合 + 交易日 + 时点”保证幂等。
- 模型建议先进入订单账本，之后只使用建议时间之后的第一根有效 1 分钟行情成交。
- 继续支持无 Key 的提示词复制/JSON 粘贴，直调 OpenAI 使用同一结构契约。

## 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 同花顺不落明文实时持仓 | 自动判断无法取得最新真实持仓 | 失败关闭并保留现有复制表格同步，不抓密码、不注入客户端 |
| 分钟公开行情延迟或缺失 | 订单不能按下一分钟成交 | 维持待成交，显示数据源与原因，绝不补价 |
| 结构化输出不兼容模型 | 无法生成订单 | 保存原文和错误，使用同一 JSON 契约手动回填 |
| 旧纸面组合已有静态持仓 | 与新模拟语义混淆 | 仅监控启用后的新决策改变持仓，页面标明启用时间和账户状态 |
