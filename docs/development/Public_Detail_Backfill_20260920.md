# 公开原始秒级价格补取

## 范围与验收

依据用户确认“获取最高频的数据来补充”，落地此前已验证的腾讯原始明细，不新增全市场轮询、账户权限或其他 UI 改版。最高频指此来源实际返回的记录，常见 3 秒，不承诺固定间隔或完整逐笔。

沿用恢复并交付的 `output/recovery-20260920/source`，不覆盖旧工作区和运行中的 EXE，不提交 Git。业务数据库不增加表；独立缓存目录保存原始响应、记录、交易日期和观察时间。

## 顺序

1. 来源解析与取数：配套 info 确认日期，分页有上限，校验页码、时间边界、连续序号，读取前后索引防止跨日。保存原始记录，拒绝伪造日期和缺口。
2. 本地缓存与异步补取：同证券去重，最多同时两个任务，无无限等待队列；失败退避、保留已有快照。盘中仅重新获取变化页和末页；无变化时不重拉全天。异步文件读写，避免阻塞窗口。
3. 图表：现有 5 秒 / 30 秒切换按需请求补取；优先返回已缓存数据和原有本机记录，同一天才合并。午休和竞价不插值，原始竞价成交单独保存，不伪装成竞价盘口。不同来源同一桶只选一条，不叠加成交量。
4. 隔离实测：重新获取 600519、000001、600584，记录实际日期、数量与输出路径；验证新服务、API 和前端契约，不自动切换生产程序。

## 实现约定

CommonJS，现有 axios，Node 内置 fs/promises、测试 runner，不装依赖。解析远端文本只使用 JSON.parse，不 eval。示例输出 `{ rows, meta: { dataSource, tradingDate, backfillState } }`。

代码位于 services/publicPriceDetailService.js、routes/market.js；前端仅修改 realtimeChart.js 和对应按钮说明；测试位于 test/publicPriceDetailService.test.js 及已有行情测试。

## 数据边界

- 秒级价格分桶为实际观察 OHLC，不等于交易所完整 OHLC。
- 原始数量与金额保留，跨市场单位未全部核实时不据此生成分桶成交量或均价。
- 请求任意历史日时只允许读取该日期已存缓存；公开接口回显其他日期不得冒充请求日期。
- 本地记录、原始公开成交、竞价盘口分开；没有的字段保留空值。
- 不自动安装、重启、打包覆盖或变更既有后台采集。
