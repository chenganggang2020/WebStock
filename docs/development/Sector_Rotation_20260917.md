# 板块资金轮动雷达（2026-09-17）

## 目标与已确认边界
用户已确认近 5/15/30 分钟流入、流出、加速排名，行业/概念分开，点击板块看采样曲线和成分股。不是账户级资金迁移，不生成买卖指令。

首版使用已接入的东方财富明暗盘榜，分别比较暗盘、明盘、合计累计模型净额。源事件时钟未知，全部称“采样间净额变化”，而非逐笔或精确分钟资金流。普通主力资金接口不稳定，不混入此序列。没有可靠同口径成交额，不编造净流入占成交额比例；展示供应商暗盘活跃度并注明分母未核验。

## 实现计划 / 验收
1. 纯计算与测试：同日同半日、同源、相同板块的近窗差额及元/分钟；与前一窗口比较速度，不计算近零基数增长率。端点允许 75 秒偏差，最大样本间隔 150 秒。午休、跨日、断流、缺失/不守恒金额不得补零或连算。
2. 后台采样与只读查询：复用 darktrade 适配器，行业/概念顺序全分页，每 60 秒运行，单飞、失败保留旧结果。总数/重复/缺页不合格整批不入库。逐页时间不一致必须披露。自动采集仅连续交易时段，关闭页面不影响，完全退出或电脑休眠即停止。仅保存本机实际采到的历史，不回填过去。
3. 页面：双向排名、速度变化排序、明暗反向/转向标记、查询条件切换防串数据。采样曲线和独立口径成分股；失败/旧数据/暖机明确可见。
4. 回归、浏览器检查、交付记录。当前程序不强制退出，不覆盖旧包。

## 结构与决定
- services/capitalFlow/sectorRotationModel.js：无 IO 的计算。
- services/capitalFlow/sectorRotationService.js：采样、文件存储、调度共用单例。
- routes/sectorRotation.js：GET /api/capital-flow/rotation（scope=industry|concept, minutes=5|15|30, metric=combined|dark|visible, 可选 code=BKxxxx）；POST /api/capital-flow/rotation/refresh 手动采一次，仍限流 60 秒。
- js/modules/sectorRotation.js 与 css/sector-rotation.css：现有资金页内独立面板。
- 数据保存在 WEBSTOCK_DB_PATH 同目录 sector-rotation/，每日独立 JSONL；不更改生产数据库结构，不涉及持仓/自选写入，不增加依赖。源原始字段和采集时间随快照保留；内存有界，历史文件不自动删除。
- GET 仅读取，后台任务或显式 POST 才采集。生产启动时挂载调度器，测试导入 server 不启动。

## 运行与验收边界
- 正式 Node 启动和 Electron 启动/退出均接入同一个服务；测试导入不自启。`WEBSTOCK_SECTOR_ROTATION_AUTO=0` 可关闭自动采样，`WEBSTOCK_BUILD_SMOKE_TEST=1` 不启用后台采样。
