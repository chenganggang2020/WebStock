# 产业链研究工作区接入（2026-09-20）

## 范围与决定

实施用户确认的三栏方案：统一主题目录；中间关系图、公司清单、待核验；右侧选中项的原文与证据。来源、导入和自动更新配置移入资料管理。继承全局浅色/中性炭黑，不新增品牌或修改数据库身份。

沿用既有分类、版本、来源、人工核验接口；未改服务端分类规则或数据库结构。`fixedWorkspace` 挂载新页面，`industryChain` 继续管理请求/保存；`industryWorkspace` 仅负责选择、展示和局部刷新。

## 数据语义

- `confirmed` 自动匹配结果显示“资料匹配 · 待核验”，不等同于研究版本的 `verified`；不显示规则分数为概率。
- 上游（材料、设备）、中游（器件、制造）、下游（应用）节点均来自接口。组内虚线表示环节归属；未提供公司间供货边时不捏造边。
- 环节未知的记录有独立计数入口，可进入待核验；不静默丢弃。服务端限量保留实际/总量覆盖计数。
- 同源证据合并展示，重复匹配描述只呈现一次；不同证据 ID、日期、哈希和原始标题仍可展开。匹配依据不冒充原文短引。
- 没有研究版本时提供来源登记流程，不填入设计稿示例。分类视图不写入版本库。

## 交互与防回归

- 目录键包含类型命名空间，切换行业/研究时取消迟到响应。
- 切换环节时同步右侧选中证据；点击节点不重建图和滚动位置。
- 未保存的来源草稿按主题隔离，切换回来保留；读取失败时配置控件不可写。
- 历史版本、版本变化、AI 分析、原文与核验审计保留在右侧折叠区。
- 默认只读取数据，配置保存、取证和人工核验仍需用户明确点击。
