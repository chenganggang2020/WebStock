# 作者工具栏与自动卡顿取证

用户已明确要求自动捕获卡顿，不依赖人工报时；现有故障为 Electron 主窗口与本机健康、静态接口同时不响应，具体阻塞点仍未证实。

## 范围与决定

1. 作者顶部默认不超过 96 CSS px（1366/1600 宽），仅当前作者选择、采集和刷新常驻；原按钮及作者隔离不变，低频设置收进默认关闭的配置区。展开配置允许自身区域滚动，不撑出整个页面。
2. 使用独立 Node 子进程看门狗而不是主线程定时器写日志；主线程堵塞时仍能落盘。随程序启动/退出，不修改 Codex 自动化或此前暂停的临时监控。
3. 主线程心跳、前端可见页面心跳、最近交互、未完成 HTTP/数据库/抖音原生操作关联；只记录固定标签、规范化路由、耗时和调用位置，不记录请求参数/正文、SQL 参数、账号信息或 Cookie。事件环形缓冲及日志滚动限制磁盘和内存占用。
4. 默认失联 5 秒触发事件，自动写恢复记录；区分主线程、可见渲染器、单接口，以及观察器自身暂停/休眠。Windows 等待链仅自动有限次采集，不暂停进程、不抓内存、不强杀、不自动重启。
5. 日志目录 WebStockData/diagnostics，提供桌面打开日志入口。诊断自身失败必须留可见降级信息且不能阻止应用启动。
