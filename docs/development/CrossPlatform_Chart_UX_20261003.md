# Windows 与独立 Android 看图体验优化

## 范围与基线

用户已批准实施并行优化。Windows 基线为 `8d67e4d`；Android 基线为独立版 2.1.1，原始交付保留在 `2e06/.../output/android-independent-20261002`。可维护 Android 源码收入 `android-independent/`，不迁移任何用户数据库、密钥或登录状态。

本轮以看股主流程为验收中心，不承诺将桌面全部采集、产业链、竞价或付费数据模块迁移到手机。两端独立运行与存储；不启动生产采集，不刷新业务数据库，不恢复已停止的自动任务。

## 分工与顺序

1. Android 页面控制：即点即开，最近浏览异步保存；行情更新不重建图表；请求期限、迟到响应与可见页面自动刷新；当前列表连续看股。
2. Windows 连续看股：明确全市场搜索和当前自选组筛选；前后股票保留周期，维持现有请求隔离与缓存回显。
3. 共享序列指标：把完整、明确版本的九转/序列计数规则作为独立纯算法，保留旧算法兼容；证据、边界、未收盘和历史核对单独测试，不宣称盈利能力。
4. 手机图表：增量更新保留缩放/读数，九转预计算，信号解释和历史覆盖可见，双端复用同一算法。
5. 隔离测试、浏览器交互验证、APK 签名与 Windows 打包。交付包与未验证能力分别报告，不自动替换生产安装。

## 可验证标准

- 股票点击无需等待保存请求；A→B→A 与周期快速切换不能被旧响应覆盖。
- 行情刷新不替换图表 DOM/实例，已选历史位置和缩放保持。
- 请求失败保留缓存与其真实时间；离开页面、应用不可见时停止重复刷新；手动刷新仍可用。
- 连续看股遵循当前列表，不改列表次序或自选分组；搜索支持代码、名称及可用拼音索引。
- 图表固定读数与最新报价分开；成交量缺失不记零，已加载历史不标成全历史。
- 算法测试涵盖缺口、相等、方向变化、未收盘、不同周期及无前视偏差；历史表现不是交易回测。
- 打包不包含生产数据、密钥、测试 fixture 或账号；旧 APK 和旧 EXE 保留。

## 验证命令

Windows：`node --test test/*.test.js`（分组运行并记录结果）；`npm run dist:win:portable`。
Android：`node --test android-independent/qa/*.test.cjs`；`android-independent/build-apk.ps1`（Java 测试、release、签名校验）。浏览器及模拟器结果独立记录；未测试的实体设备明确说明。

本轮逐项结果、全仓旧失败、真实来源取样及最终交付记录见 [验证记录](CrossPlatform_Chart_UX_Verification_20261003.md)。安卓公共算法文件由构建脚本同步，四个模块须与桌面源文件逐字节一致，不维护另一套计算口径。
