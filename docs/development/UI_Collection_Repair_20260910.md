## 已验证的原因和恢复

1. Windows 已存在 WebStock 具名启动项，但 Electron 的 openAtLogin 返回 false；同次结果 launchItems 中该项 enabled=true、executableWillLaunchAtLogin=true。修复按具名项及实际路径判断，并测试重新启用及回读成功。未注销或重启电脑。
2. 当前 portable 数据目录缺少量化环境关联。通过运行程序的 `/api/quant/runtime/link` 关联既有 Python 3.12 环境，导入检查通过。
3. 当前数据目录缺少已下载的 small 识别模型。将原目录完整 small 模型复制到当前目录，保留原模型。turbo 权重不完整，未宣称其可用。
4. 运行中旧程序的第 119 次采集已真实完成视频 7681209106778645105 的本地转写，耗时 254.35 秒，并继续下一条。证据在 `artifacts/validation/ui-repair-20260910/live-asr-recovery.json`。
5. 旧采集每轮实际只读首屏 20 张卡片；本地最新日期为 2026-09-03。新版增加有限滚动与队列优先级，但不能据此断言已经覆盖作者所有最新作品；需新版运行后继续核验实际平台可见内容。
6. 部分旧封面接口返回不可用，页面保留“封面待补采”；这与语音环境故障是不同问题，未将补采前的旧视频全部标成修复完成。
