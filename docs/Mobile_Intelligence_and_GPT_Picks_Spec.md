# WebStock 移动智能看板与 GPT 选股导入一期规格

## 目标

让 iPhone 私网网页从“账户快照”升级为只读研究看板，并允许用户把 ChatGPT 对话中每天筛选的 10–20 只股票及原分析粘贴导入 WebStock AI 研究中心。

## 一期范围

1. 移动看板展示持仓、自选、重点资讯、连续资讯流、资金动量、最近智能选股和 GPT 导入候选。
2. 重点资讯只能依据可审计字段标识，并显示重要原因；无来源证据时不生成“全网热度”。
3. 资金动量必须同时显示来源、观测时间、可用性和降级原因；缺失数据保持为空。
4. 持仓与自选界面可每秒刷新本机最新快照，但外部行情请求必须有界、合并并缓存；每个价格显示 `fetchedAt`、`changedAt`、`stale` 和来源。
5. GPT 导入接受文本、Markdown 或 JSON，识别 A 股 6 位代码、名称、理由、风险和原分析；去重并限制最多 20 只。
6. 导入来源固定标记为 `manual-chatgpt`，保存导入时间和原文；不读取 ChatGPT 账号历史，不要求 OpenAI API 密钥。

## 明确不做

- 不自动交易、不自动加入真实持仓。
- 不把一秒 UI 刷新描述为一秒交易所行情。
- 不绕过数据商频率、授权或 Level-2 权限。
- 不把 GPT 输出、本地评分、降级新闻或人工名单包装成已验证投资结论。
- 不在手机端开放数据库写操作；GPT 导入仅在 Windows 完整工作台执行。

## 数据与刷新口径

- UI 心跳：可见页面每 1 秒读取本机快照；隐藏时停止。
- 外部报价：仅持仓与自选的去重代码集合，按服务端最短间隔刷新；并发请求合并，失败保留最后成功值并标记过期。
- 分时图：继续按上游真实粒度展示，不通过插值伪造逐笔或 1 分钟数据。
- 资讯：移动快照只返回有界字段和条数，完整列表按需继续加载，避免传输数百 KB 原始包。

## 验收标准

- 390×844 和 430×932 下无页面级横向溢出，资讯能连续滚动到底。
- 重点资讯同时显示级别与至少一个可复算原因。
- 资金不可用时页面明确显示不可用原因，不显示零值假数据。
- 没有筛选历史时显示空状态，不用自选股冒充智能选股。
- GPT 文本可导入 10–20 个去重候选，恶意 HTML 只作为文本保存和显示。
- 一秒心跳不产生一秒一次的外部行情请求；隐藏页不刷新；并发请求只有一个上游调用。
- 聚焦 Node/API 测试、真实 Edge 手机验收和完整 Node 回归通过后才能重新打包。
