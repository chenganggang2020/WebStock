# 首页指数详情与细分板块 V4 规格

## 目标

首页在保留指数联动对比的基础上，补齐两个直接使用场景：

1. 点击任一主要指数卡片后，在首页打开大图详情，可切换分时和日线。
2. 板块云默认展示交易语义更强的概念主题；行业分类改用申万二级等细分口径，不再默认展示“机械行业”一类老式粗分类。

## 数据边界

- 指数分时盘中每 15 秒强制刷新；休市后显示“最近交易日分时”和实际交易日期，不声称实时。
- 板块快照盘中每 60 秒强制刷新；休市后降低频率，不重复声称价格正在变化。
- 东方财富板块接口可用时优先使用其板块行情与供应商分类资金字段。
- 东方财富不可用时：
  - 概念使用新浪“热门概念”目录与完整成分股聚合快照；
  - 行业使用新浪“申万二级”目录与完整成分股聚合快照；
  - 不使用新浪旧“新浪行业”作为首页默认板块云。
- 本机同花顺 `BlockUpdate/block_2B.ini` 只作为概念名称和成分归属的本地目录证据；没有实时板块涨跌和净流入字段时，不冒充实时行情。
- 公开源或本地目录只要覆盖不完整，页面必须显示“部分可用”和已纳入数量，不补 0、不生成模拟板块。

## 指数详情交互

- 指数卡片可点击，也可用键盘 Enter / Space 打开。
- 弹窗展示指数名称、代码、点位、涨跌幅、数据日期和截至时间。
- 分时大图展示实际分钟价和昨收参考线；盘中刷新后，已打开弹窗同步更新。
- 日线大图展示 OHLC K 线和成交量，默认使用当前已加载窗口。
- 弹窗支持分时/日线切换、关闭按钮、遮罩关闭和 Escape 关闭。
- 打开或关闭弹窗不改变首页主对比对象和相关性矩阵。

## 板块分类

- 默认标签为“概念热点”，覆盖商业航天、消费电子、小金属、有色铜/铝/锌、先进封装、半导体设备、光通信、算力、人形机器人等主题。
- “行业细分”采用申万二级，示例包括消费电子、小金属、半导体、通信设备、航天装备等。
- “地域”保持独立分类。
- 概念是多对多主题归属，不等同于交易所行业层级；行业用于产业位置，概念用于主题/事件/产业链交叉观察。
- 热力图面积仍为板块成交额，颜色仍为涨跌幅；因此成交活跃且涨跌显著的主题自然更醒目，而不是按名称手工标记“热门”。

## 验收标准

1. 点击八个指数中的任一个都能打开大图；分时和日线都可渲染，关闭后首页状态不丢失。
2. 盘中指数详情 15 秒刷新，板块快照 60 秒刷新；休市时明确显示最近交易日。
3. 东方财富不可用时，概念接口不再整类空白，并至少能返回商业航天、消费电子、小金属和有色相关主题中的可用快照。
4. 行业降级分类来自申万二级，页面不再默认出现新浪旧“机械行业”粗分类。
5. 首页默认打开“概念热点”，切到“行业细分”或“地域”后可重新加载。
6. 来源、抓取时间、覆盖数量和降级原因常驻；资金字段缺失时资金模式仍明确不可用。
