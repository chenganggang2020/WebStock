# 独立安卓 2.2.0 看股体验优化版

将 android-independent 目录的 `WebStock-Android-Independent-2.2.0-20261003.apk` 传到安卓手机后打开安装。系统若询问是否允许该文件来源安装应用，按系统页面操作。应用要求 Android 8.0 以上及支持现代网页语法的系统 WebView；本轮未完成实体手机验收。

打开后直接进入手机工作台，不需要电脑地址、配对码、同一个 Wi-Fi 或电脑保持运行。行情需要手机联网；离线仍可管理已保存的自选、账户账本和资料，旧行情保留原交易日。

电脑继续使用原 Windows 程序，两端分别保存自己的数据。目前没有自动同步；安卓“手机设置”可导出 / 合并独立安卓 JSON 备份。备份不包含 AI 密钥。卸载前应主动导出需要保留的记录。

安卓升级包沿用原签名与包标识。本轮在隔离模拟器验证从2.1.1覆盖安装后自选、账本、资料保留；请直接更新，不要先卸载。它不读取旧电脑配对设置，也不会自动迁入电脑或旧连接页面中的私人记录。

查看股票后可在当前列表连续切换，分时/日K/周K/月K使用快捷标签；横屏全屏保留周期选择和指标设置。图表选项中的“加载更早历史”分批请求历史，最多保留当前会话5000根，不代表全历史已下载。后台休眠后回到应用会重新检查；刷新失败仍显示有时间标识的旧缓存。

信号按钮展示九转公开规则版的计算说明与已加载历史核对；日周月K为9+13，分时只有真实分钟价格序列的基础1–9。它不是商业版授权认证，也不是买卖建议或策略收益证明。

手机默认没有配置 AI 服务。需要 AI 时，在手机设置填写自己的服务地址、模型与密钥；密钥通过安卓系统密钥库加密保存，直接调用服务商。公开行情与本地记录不需要收费服务器，AI费用取决于你选择的服务商。

本版是独立运行的基础版。集合竞价、原明暗盘模型、完整产业链关系、采集转写、模拟组合等尚未迁移，逐项见“迁移状态”和《功能迁移清单》。不能用本版替代电脑版全部研究功能。
