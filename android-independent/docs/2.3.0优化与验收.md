# Android 2.3.0 优化与验收

日期：2026-10-05。电脑和安卓仍各自独立运行、独立保存，不依赖电脑服务，不自动同步。

## 已实现

| 工作流 | 本轮结果 |
|---|---|
| 账户统计 | 按账户、起止日期和股票查看交易费用、买入支出、卖出净收入、已实现盈亏；按股票汇总；显示累计已实现盈亏曲线 |
| 统计口径 | 先按完整账本计算含费用的移动平均成本，再筛选；保留精确十进制金额，汇总后舍入；不使用当前价虚构历史净值或收益率 |
| 账本联动 | 显示每笔卖出盈亏，按买卖筛选；统计和持仓可跳转对应股票账本，持仓可预填卖出表单；删除最后记录后清除失效股票筛选 |
| ETF | 涨幅、跌幅、成交额三种榜单；东方财富失败后使用新浪备用源；双源失败保留同一排序缓存；价格保留三位小数，来源在首屏可见 |
| 数据来源 | 成交额单位元，不冒充净流入或申赎；新浪榜单不提供交易日期时明确标未知，补充报价的日期单独显示 |
| 看股体验 | 保留 2.2.0 的 640 根首批日周月K、更早历史、原位刷新、缩放保持、公开9+13序列、分时均价和成交量 |

## 仍未完成

- 行业、概念和个股资金榜单的主数据源仍不可用；不使用成交额冒充资金流。
- 净值/总资产历史曲线、收益率、分红及独立税费交易尚未与桌面完整对齐。
- 原明暗盘、竞价、产业链关系、采集转写、纸面组合等仍待迁移。
- 未进行物理手机或 Android 17 系统验收；付费 AI 和后台采集不在本轮验证范围。

后续优先处理有真实可用来源的行业/概念数据，以及有价格历史与现金流支持的账户资产曲线。保持数据缺口可见，不把未实现入口计作完成。
