# 独立安卓功能迁移清单

基线：正式电脑源码 8d67e4d（2026-09-28），27 页面。当前独立安卓 2.2.0（2026-10-03）重点优化看股流程，尚未与电脑版全功能等价。本目录旧版设计/验收记录仍保留原日期，不能当成本版验证结果；本版记录见仓库 docs/development/CrossPlatform_Chart_UX_Verification_20261003.md。尚无物理手机验收。未在本轮重新测试的数据源沿用上一轮观察，不代表当前实时可用。

同花顺 Windows 自选文件读取在手机侧改为主动导入，不能读取另一台电脑的本地文件。采集登录、验证码由用户在对应手机流程完成；尚未迁移的入口应显示状态，不能继续调用电脑或暗中改成云执行器。

2.2.0 的刷新只在应用可见且相关页面打开时运行；退到后台暂停、返回后补检查，不是手机后台持续采集。网络失败保留实际缓存及旧时间，不伪造实时数据。公司拼音目录在打包时从本仓库目录生成（名称、代码、拼音全拼与首字母）；目录以外的六位代码可以向来源查询，是否有效以实际响应为准。
