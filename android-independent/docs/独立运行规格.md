# WebStock 独立安卓应用

2026-10-01。用户明确纠正：电脑与安卓是两个各自独立运行的程序。旧版 1.2.1 的电脑配对、网关和远程 WebView 方案不符合要求，不能继续作为独立版交付。

## 验收条件

- 首次打开直接进入手机工作台，无电脑地址、配对码或电脑连接步骤。
- 安卓界面、业务处理和数据存储均在 APK/手机内；行情直接向互联网数据源请求，电脑程序退出不影响安卓运行。
- 自选、账户交易、研究资料和配置各自保存在手机，不读取、不修改电脑数据库。
- 离线可打开应用、管理本地记录和回看已缓存数据；旧行情显示交易日与缓存状态，缺失行情不填零。
- 联网取得真实行情，显示来源、数据日期与获取时间。AI 使用手机自己的配置，不获取电脑密钥。
- 可构建、签名、安装；验证区分纯业务测试、模拟器运行和安卓真机运行。
- 所有功能逐项记录状态。电脑版的 Windows 文件、浏览器执行器、Python/ASR 依赖必须迁移或明确未完成，不能以空页面代替实现。

## 结构与实施顺序

`android/`：Java 原生壳、SQLite 本地存储、HTTPS 数据客户端、只向内置页面开放的消息桥、系统导入/导出。

`web/`：随 APK 打包的手机工作台与本地 ECharts，使用商业行情软件的信息层次，红涨绿跌、可触摸报价行、深浅主题。

`qa/`：业务测试、真实网络取数、模拟器验收和打包证据。`docs/`：迁移清单、验收边界和操作说明。

先验证行情/自选的独立闭环，再实现账户和研究闭环；采集、转写、原电脑版资金模型和其他模块按功能清单迁移。安卓独立运行不等于完全断网运行，不引入收费服务器或电脑常开条件。默认两端不自动同步；数据迁移采用用户主动导入/导出，不自动复制个人数据库或密钥。

## 当前范围待澄清

已询问用户是否要求全部电脑版功能同步迁移，或先交付独立的行情、自选、账户和研究。等待期间仅实施两种选择都需要的本地运行基础。功能状态必须随代码、测试及真实运行证据更新，不能预先标为完成。

## 实用命令

构建：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File build-apk.ps1`

业务测试：`android/gradlew.bat --no-daemon test`

模拟器验收：用 SDK 的 adb 安装测试 APK 后运行本项目的 Instrumentation，记录本地读写及关闭电脑服务时的取数结果。

## 边界

保留原交付与当前正式电脑程序。只在本目录实施独立版，不把原配套 APK 重命名为独立版，不打包数据库、会话或密钥，不连接券商委托或执行实盘交易。
